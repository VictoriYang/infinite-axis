## 1. 人类数据的增益跟着对齐程度走，不跟着小时数走

**InternW0-Δ: A World Action Model Bridging Predictive Dynamics and Actions with 20K+ Hours of Open Data** · [arXiv](https://arxiv.org/abs/2609.31394) · [项目页](https://internrobotics.github.io/InternW0-Delta/)

上海 AI Lab InternRobotics 的世界-动作模型技术报告。架构是 Mixture-of-Transformers：一个预训练的视频 expert（Wan VAE 潜空间）和一个动作 expert（flow matching，32 步 chunk）耦合，冻结的 VLM 给动作 expert 提供任务语义，Track4World 做训练期的 4D 几何与运动蒸馏。「Causal Imprint」是它处理「视频预测怎么变成动作」的办法：把未来帧潜变量的相邻差分只当训练监督，让一组可学习 token 从当前观测里编码「接下来会变什么」，推理时不 rollout 视频，一次视频侧 prefill 缓存 K/V 后只做动作去噪。数据侧把 AgiBotWorld、RoboMIND、RH20T、EgoDex、EgoVerse、Hy-UMI-10K 等十几个公开集统一到一个 **80 维固定语义槽位的动作空间**——关节动作用绝对目标位，末端状态用 3D 位置加 6D 旋转，末端动作用 3D 平移增量加局部系 3D 旋转向量——处理后 20K 小时以上，称将开源训练代码、权重、数据管线和处理后的数据。

报告里最值得抄的是三组同架构、同下游、只换一个变量的消融。

**数据源消融。** LIBERO-Plus 上无预训练 78.59，加原始第一人称视频 80.45，加 Ego2Robot 转换后的数据 81.86，加 UMI 83.24，加机器人示范 83.73。RoboTwin 2.0 的 Clean2Random 设定差距更夸张：2.80 → 3.13 → 6.66 → 13.90 → 32.34。作者自己的结论是「人类数据的价值随观测/动作空间与机器人的对齐程度单调上升」，并在 Limitations 里承认对第一人称数据的转换策略、配比、监督形式都还没系统研究。这个结论限定在当前规模和以夹爪为主的基准上，作者也说灵巧手任务上人手数据可能更有用。

**VLM 选型消融。** 同设置下 Qwen3.5-2B 60.37%，换成 RynnBrain1.1-2B 69.08%，差 8.7 个点——比后面 Causal Imprint（+1.7）、对齐损失（+5.7）、4D 蒸馏（+1.9）任何一项架构组件都大。backbone 该当一个独立的消融变量，不该当默认项。

**稀疏记忆上下文。** 只加三帧——回合起始帧、上一个 chunk 之前的帧、当前帧——成功率 49.59 → 53.47。单帧观测确实不够，但也不需要密集历史。

部署数字也给了：单张 RTX 5090、30 Hz、32 步预测每 16 步异步推理一次，RTC 用训练期前缀条件化，并对比了三种 RTC 策略在 chunk 边界的动作跳变比（VJP 8.94、硬前缀 7.13、训练期条件化更低）。跨本体是同一预训练 checkpoint 分别给四套硬件（AC-One、Arx5、Franka+XHand、TianJi+Wuji）后训练各自的 action adapter。

这篇改变的是对第一人称人手数据的预期。此前的默认假设是人手数据主要卡在规模，多采就行；这组消融说在当前规模下原始视频几乎不涨，涨的是转换之后的部分。采集端的进度该用「转换后在真机基准上涨了多少」来计，而不是用小时数。

## 2. 重定向丢掉的接触信息，下游 RL 补不回来

**Morphometric Imitation: From Morphology and Contact Aware Hand Retargeting to Sim-to-Real Visuomotor Policy** · [arXiv](https://arxiv.org/abs/2609.28660)

Berkeley（Malik、Tomlin、Sastry 联合指导，Haozhi Qi 参与）。三段式管线：GRAB 数据集里的人手-物体交互（MANO 手 + 物体网格）→ 形态与接触感知的运动学重定向 MMO → 用物体位姿和接触信息做 residual RL 得到动力学可行的机器人示范 → 蒸馏成点云视觉运动策略零样本上真机。三只手（Dex3 三指、Allegro 四指、Sharpa 五指），十个 GRAB 轨迹；真机是 KUKA iiwa14 加 Sharpa Wave 加 RealSense L515，硬木桌面无缓冲，30 个物体 300 次试验 89.3% 零样本成功，每类不低于 80%。

方法本身不算新范式，有用的是评测指标和隔离实验。指标是**位置感知的接触 F1**：机器人不仅要用对应的手指或手掌接触，还要接触在物体表面同一位置（5 mm 容差，按网格面积加权），加上接触 patch 距离。MMO 对五个开源重定向基线（DexPilot、AnyTeleop、Position、Contact PyRoki、OmniRetarget）在三只手上 F1 分别高出 8.3、27.8、10.5 个点。更关键的是 Table III：**同一个 residual RL 配方、只换运动学参考**，成功率 Dex3 53.2 → 82.5，Sharpa 56.5 → 91.8，Allegro 68.2 → 69.9。residual RL 的消融显示物体位姿负责轨迹跟踪和任务完成，接触信息负责保持示范的交互方式，两者互补。

这篇改变的是对重定向环节的看法。此前容易把人手到机器手的重定向当成运动学精度问题，觉得反正后面有 RL 兜底；这组隔离实验说 RL 补不回重定向阶段丢掉的接触信息，30 个点的差距全来自参考。所以人手数据转机器人示范时，重定向的目标函数和验收指标应该是接触保真度——哪部分手接触在物体哪个位置——而不是关节角或指尖位置误差。手套加动捕的采集管线如果能顺手记接触，就该记。

## 3. 异构输出下的分段优势估计（LLM 侧，仅备案）

**SLCA-GRPO: Resolving Cross-Segment Credit Misattribution in Tool-Calling RL** · [arXiv](https://arxiv.org/abs/2609.29050)

LLM 工具调用侧的工作，和具身没有直接接口，收进来只因为方法可迁移。问题是 GRPO 把一个轨迹级标量优势广播给所有 token，而工具调用 agent 的输出是异构的——结构化工具调用加自然语言总结——总结部分的梯度噪声会污染工具决策 token。做法是在同一组 rollout 内按结构段落分别估计优势，不需要从中间状态额外采样，配合分层奖励把执行优势路由给工具 token、偏好优势路由给总结 token。7B 上比 GRPO、ToolPO、RLTR 高 2.5（域内）、1.4（BFCL）、9.2（τ²-Bench）个百分点。

对具身的接口：先输出 CoT 或 grounding 文本再输出动作 token 的 VLA 做 RL 时，输出同样是异构的，「文本段的优势污染动作段」是同一个结构问题。这篇只提供了一个可以套用的框架，没有具身实验，只读了摘要，算备案。
