## 本周三条趋势

**一、world-action model 开始分化预测目标。** 池子里六篇在讨论「预测未来能不能让动作更好」，但没有一篇还在单纯预测 RGB 未来帧。Flex-π 预测 3D pointmap 和 object-centric 语义，FACT 预测任务进度，JEPA-WAM 预测阶段级语义目标。共识似乎是：像素级未来里绝大部分比特与控制无关，问题从「预测得准不准」变成了「预测什么」。

**二、语言和时间是两个不随本体变的监督锚点。** 多数据集混训绕不过一个问题：不同机器人之间共享什么监督信号。本周两篇给了两个不同的答案，而且都刻意避开了人工标注。SALT 用语言——要求量化后的动作 latent 能反解出指令；RynnValue 用时间——从时间戳直接推出到目标的有向 cost-to-go。共同点是都在批评一类 task-internal 的监督（重建误差、normalized progress）：它们在单一数据集内看起来合理，跨本体就失效。

**三、评测协议本身成了一等问题。** 两篇独立的工作从不同方向指向同一件事：单步预测精度对长程规划成功率没有预测力。一篇独立复现实测同一个 checkpoint 只改目标构造方式，成功率从 84% 掉到 8%；另一篇（VIScore）提出把诊断从 latent 空间扩展到 encoder / predictor / planner 三处。如果这两篇成立，那么大量以预测 loss 为主要指标的世界模型工作，其结论的可比性是存疑的。

## Top 5

### 1. Flex-π: A Multi-Stream World-Action Model with Compute Flexibility

[arXiv 2608.10860](https://arxiv.org/abs/2608.10860) · [项目页](https://flex-pi.github.io/) · 作者含 Dieter Fox

核心发现是个便宜的 free lunch：冻结的视频生成 VAE 不经任何 pointmap 专门训练，就能近乎无损地编码 3D pointmap。于是可以在不加传感器、不重新预训练、不加推理延迟的前提下，把 3D 几何、object-centric DINO 语义和 RGB 塞进同一个 latent 空间，在 Mixture-of-Transformers 主干里与动作联合去噪。

更值得注意的是 per-stream dropout + cross-modality forcing：一个 checkpoint 就能跑任意子集的流，从「只出动作」的快模式到全联合生成。实测比 π0.5 更快，真机双臂精细任务上超最强基线 2–7×。

「一个权重支持多档算力」这个性质，比为延迟单独训一个小模型划算得多；而「多路监督共享一个 latent + 训练时随机丢流」是可以直接搬的配方。

### 2. RynnValue: Scaling Robotic Value Foundation Models with Temporal Distance

[arXiv 2608.09853](https://arxiv.org/abs/2608.09853) · RynnBrain 系列，开源

要解决的是 preference 和 normalized progress 这两类监督锚点都是 task-internal、跨本体跨数据源迁不过去的问题。换成 temporal distance——从当前观测到语言指定目标的有向 cost-to-go——因为标签可以直接从时间戳推出来，不需要任何偏好或进度标注就能吃下 7000+ 小时、约 300 万条指令条件片段。为防止大规模下学到捷径（预测对失败和回退不敏感），用了随机时序采样、时序打乱、value-isolation attention 三件套。

无偏好标注训练的 Kendall's τ_a 达到 0.675，超过全量偏好监督的 SOTA（0.655），是纯 progress 版本（0.292）的两倍多，零样本泛化到未见任务 / 本体 / 视角。转成 potential-based shaping 的稠密奖励后，真机成功率 52.5%→72.5%（online）、63.8%→82.5%（offline）。

用时间戳当标签这个思路，对手上已有的多数据集 lerobot 数据基本零成本；而且它顺带就是个 failure-recovery 数据的自动筛选器——值回退处即失败点。

### 3. SALT: Aligning Action Representations with Language in VLA Models

[arXiv 2608.10484](https://arxiv.org/abs/2608.10484) · CMU，Yonatan Bisk 组

论点很干净：动作 tokenizer 用 L1/L2 重建损失优化，而在原始动作空间里「数值接近」并不等于「语言语义上接近」，于是纯重建式离散化会系统性磨掉动词信息——不只是做成了什么，还有怎么做的。

先在 BridgeV2 上证明动作轨迹里确实带有超出视觉状态变化的动词接地信息，然后给 VQ-VAE tokenizer 加一个辅助目标：要求一个冻结的 VLM 能从量化后的动作 latent 里还原出这一 episode 的指令。SimplerEnv 上 71.9%，对比纯重建 VQ-VAE 42.7%、FAST 31.2%，学出了动词特化的 code，重建精度没掉。

这篇的杀伤力在于它说明重建误差是个会误导人的表示质量指标。而「latent 能反解指令」这个辅助 loss 成本极低，且目标天然跨本体共享——语言是唯一不随本体变的东西。

### 4. FACT: Failure-Aware Causal Training for World-Action Models

[arXiv 2608.10232](https://arxiv.org/abs/2608.10232) · [项目页](https://fact-wam.github.io/) · Xiaolong Wang 组 + Nicklas Hansen

指出现有 WAM 的一个结构性问题：世界模型基本只在成功示范上训，所以它根本没有理由去预测「坏动作会导致什么」——无论是生成未来视频再用逆动力学反解，还是把预测视频当目标条件，都绕不开这点。

FACT 把接口改成 action-conditioned：给定实际执行的动作，预测未来视频和任务进度。这样 failure rollout 就成了合法的监督目标而不是被丢掉的数据，进度预测器同时见过成功和失败的后果，推理时还能用来给候选动作打分。仿真与真机双臂上都超基线，且失败数据加得越多越好，显著减少了「对着坏动作也幻觉出成功未来」的现象。

「加失败数据单调变好」这条 scaling 结论如果在 RoboTwin 上复现得了，等于给数据自生成闭环找到了一个不依赖成功率的价值出口。

### 5. The Evaluation Protocol Determines the Result（LeWorldModel 独立复现）

[arXiv 2608.10145](https://arxiv.org/abs/2608.10145) · 单作者，约 25 美元租算力 + 一台笔记本 CPU

内容比很多 SOTA 有用。硬结论四条：

1. 要复现到报告数字，需要四个在任何发布配置文件里都找不到的约定（frameskip 块内 dense action gathering、程序化设定的 action encoder 宽度、ImageNet 像素归一化、action z-scoring）。只照发布配置跑，predictor 根本不收敛。
2. 论文附录和仓库配置给了互相矛盾的 goal offset 和步数预算，用作者自己的权重跑分别是 14.0% 和 84.0%。
3. 同样 50 个 episode，只改目标怎么构造，同一个 checkpoint 从 84.0% 掉到 8.0%。
4. 两条可泛化的发现：单步预测精度不预测长程规划成功率（三个 checkpoint 预测误差差 7 倍，能单调排序短程成功率，对长程完全无序）；一个 BatchNorm 层把验证 loss 虚高了最多 300 倍，掩盖了训练 loss 全程没动。

第 3 条是这篇最该被引用的地方：评测目标的构造方式比模型差异更能左右结论。实践含义很直接——goal 构造方式和步数预算必须写进 benchmark 配置并锁死。
