## 1. 参数量只解释 15% 的边缘推理延迟方差

[VLA-HWBench](https://arxiv.org/abs/2610.34717) 把 18 个开源 VLA 模型跑在 NVIDIA Jetson AGX Thor 和 AMD Ryzen AI Max+ PRO 395 上，把一次推理拆成七个阶段分别计时，并且在同一批模型上横向比较各种推理优化。以往的同类研究最多拆三段，而且不在同一组模型上做对比，所以"优化到底省在哪一段"一直说不清。

三个结论。**第一，动作生成策略比模型大小重要得多。** 它主导了 19 个 Jetson 配置里的 14 个；延迟跨配置在 Jetson 上差 82 倍、在 AMD 上差 157 倍，而参数量最多只能解释 15% 的延迟方差。用少数几步 flow matching 一次吐出长 action chunk 的模型跟得上控制频率，逐 token 解码的跟不上。

**第二，kernel fusion 配 4-bit 权重收益最大**，让两个具体模型比 PyTorch 加 `torch.compile` 快 2.6 到 2.9 倍——但这条优化只对这两个模型、而且只在 Jetson 上存在。更值得注意的是作者的一句观察：优化会把时间推到它最压不下去的那个阶段。其中一个模型的 CPU 预处理占比，在优化之后从 12% 涨到了 39%。

**第三，优化之后，显存带宽只卡那些处理 token 很少的阶段**（比如去噪步），其余阶段全是软件卡的——未融合的 kernel、host CPU 上串行的预处理。

这篇改变的是排查顺序。"边缘端跑不动就换更小的 backbone、加速首选量化"是个很自然的直觉，而这组数字说明参数量基本不是主要变量，动作生成方式才是；并且做完 fusion 和低比特之后，瓶颈会搬到 host CPU 的串行预处理上去。延迟预算表应该先定"一次推理出多长的 chunk、几步去噪"，再给 CPU 预处理单独留一栏做并行化。

## 2. prune 还是 reuse，不该全局二选一

免训练的 VLA 加速器都在做同一件事：每个控制步只重算一部分视觉 token，剩下的要么剪掉（prune），要么复用缓存的 KV 状态（reuse）。两者省下的算力几乎一样，而已有方法都是对所有被跳过的 token 只用其中一种。

[TRIAGE](https://arxiv.org/abs/2610.34519) 做了一个 token 级诊断，指出该用哪一种取决于该 token 的 **drift**——它的浅层 value 相对于缓存被计算时刻的变化量。在两个测试过的 backbone 上，drift 低于某个阈值时，复用并不比剪掉差；超过阈值之后，复用带来的动作误差最多是剪掉的 **4.4 倍**。阈值本身可以用同一套诊断按 backbone 校准。

于是 TRIAGE 把 token 三分：重算固定预算的一批（优先那些缓存已失效的重要 token），复用缓存仍然有效的，剪掉其余。prune-only 和 reuse-only 只是这个划分的两个极端。因为预算固定了重算数量，它直接决定 prefill 延迟。LIBERO 与 SimplerEnv 上平均成功率与全量重算相差 3 个百分点以内，Jetson AGX Orin 上 prefill 延迟最多降 48%；在只重算 7% 视觉 token 的设定下，LIBERO-Object 上比最强基线高 24.4 个百分点。

值得注意的是这个改动有多便宜：不改模型、不重训，在已有的 token 跳过逻辑里加一个 drift 阈值和一个缓存年龄判据就行。把"全局挑一条加速路线"换成"逐 token 分流"，代价是一次诊断，收益是避免 4.4 倍的动作误差。

## 3. 世界模型监督买到的不是泛化

[这项工作](https://arxiv.org/abs/2610.34593)在 FastWAM 和 OpenWAM 两个 World Action Model 家族内部做受控消融：只开关未来视频预测这一项损失，架构、初始化、机器人训练数据、训练步数在各家族内部全部固定。

结果分三层。干净条件下的**已见任务**，预测监督分别带来 24.38 和 72.91 个百分点的成功率提升——这个幅度足以解释这条路线为什么受欢迎。轨迹聚类进一步显示增益落在若干粗粒度轨迹簇的内部，包括那些簇频率几乎没有变化的情况，说明收益不只体现为轨迹模式分布的改变。

但这些好处**在分布偏移下并不稳定持续**：未见任务上的提升随模型和任务波动，而在所评估的环境随机化下，两个模型成功率都很低，预测监督没有一致优势。

最后一组实验最有实用价值：把未来视频预测当作一个辅助训练目标加到 π0.5 上，只在训练期用一个轻量 Transformer predictor，成功率从 82.94% 升到 89.19%。

把三层放在一起，这篇改变的是"要不要为了世界模型去背一个大的预训练 video DiT"这个决策。给策略加未来视频预测监督，直觉上买到的是泛化能力——毕竟它在学物理。而这组消融把增益定位在"已见任务加干净条件"，并且说明六个点可以靠训练期的一个轻量 predictor 拿到。那么它就该当成一个便宜的辅助损失来上，而不是当成架构主干的理由；想要跨环境泛化，得另找办法。

## 4. 把"对齐动作空间"整个绕开

[RynnVLA-Latent](https://arxiv.org/abs/2610.34356) 处理的是跨本体数据混训最硬的那个障碍：不同机器人的控制空间互不兼容。它的选择是不去对齐各家的原生控制量，而是用 RynnLAM 从视觉转移里学一套连续的、3D-grounded 的潜在动作，让策略去预测潜在动作 chunk（flow matching），最后才把预训练骨干和 action expert 适配到具体本体的真实动作上。

和以往潜在动作工作的差别在监督信号怎么构造：残差未来特征预测、相机补偿的 3D flow 监督、相机运动解耦，三件事都是为了让表示抓住"与控制相关的运动"而不是画面变化。规模上用了 30.1K 小时的人类、机器人与仿真视频，产出 7.455 亿条潜在动作描述符。最终 4B 策略在 LIBERO 拿 98.8%、LIBERO-Plus 84.7%（没有做基准专用适配）、VLABench 五个 track 平均 51.9%、RoboTwin 2.0 双臂 88.6%，六个真机任务上也是所比方法里最高的，覆盖灵巧手与移动夹爪两类平台。

这里面最值得抄的是**相机运动解耦**那一项。一旦把对齐挪到带 3D 结构的潜在动作层，决定表示质量的就不再是投影头怎么设计，而是相机运动有没有被剥掉——同一个动作在不同相机位姿下的视觉转移完全不同。这意味着异构视频语料的分组标准，应该先按相机运动特性分，而不是先按机器人本体分。

## 5. 动作表示预训练是一个独立的 scaling 维度

[ARPG](https://arxiv.org/abs/2610.34453) 的论点很干净：示教数据稀缺的时候，有限的机器人数据被迫同时承担两件事——学动作表示，和学任务条件下的动作分布——结果两件都学不好，下游生成模型也就吐不出复杂的灵巧动作。

做法是把两件事显式拆开。先在大规模人类操作数据上预训练一个动作表示 encoder，然后冻住它，再在这个表示空间里训一个只有 130M 参数的紧凑生成骨干，去学任务条件分布。DexJoCo 基准上取得 SOTA；双手灵巧操作的平均成功率从 π0.5 的 10.1% 提到 44.7%。扩展实验显示，人类操作行为的覆盖面越广，下游表现越好。

从 10.1% 到 44.7% 这个跨度值得停一下。它说明在动作空间复杂的灵巧操作场景里，"表示和分布抢同一批稀缺数据"是主要的损失来源，而不是次要因素。顺带的推论是：人类第一人称数据的用法不止是"当额外的示教"，更该优先用来训那个会被冻结的表示 encoder。而 130M 的生成骨干也说明，拆开之后策略侧可以做得相当小。

## 6. 同一布局里只换一句指令，成功率从 41.6% 掉到 16.1%

[BEHAVIOR-Spatial](https://arxiv.org/abs/2610.34051) 建在 BEHAVIOR-1K 上，把空间理解拆成三样分别测：空间问答、点式目标 grounding、机器人动作。规模是 49 个活动里 3,256 道空间题、14 个操作任务里 1,240 条 grounding 查询，动作评测覆盖这 14 个操作任务加 10 个导航任务。

关键在操作协议的设计。它既测 held-out 配置，也测另一种情况：**布局完全不变，只把指令里要求的目标换掉**。基线在 held-out 配置上拿 41.6%，而指令一换只剩 16.1%。VLM 适配和机器人数据预训练对此帮助都有限，但给出 oracle 视觉目标提示能把两者分别拉到 60.3% 和 38.0%。

oracle 提示把 16.1% 拉到 38.0% 这件事是有诊断意义的：它说明那部分失败发生在 grounding，而不是控制。换句话说，用操作任务成功率去代理空间理解能力（能抓对就说明看懂了）是不成立的——高成功率里有很大一块来自对布局的记忆。"固定布局、只换目标"这一组对照应该成为任何泛化声明的前置条件。作者还观察到，VLM 的问答与 grounding 准确率和 VLA 操作表现之间的相关性是随策略而变的，这对"先把 VLM 的空间题刷上去"这条路也是个提醒。

## 7. 接触密集任务的第三级，目前是零

[PhysLadder](https://arxiv.org/abs/2610.34527) 设计了 16 个家庭任务，按累积难度分三级：L1 是接触点选择与几何对齐，L2 是持续接触中的力调节，L3 是协调性的接触重构加力调节。每个任务在物理和视觉都匹配的仿真与真实环境里各实例化一遍，任务定义与成功判据共享。

他们零样本评测了一个前沿模型，每个任务每个环境各 3 次。真机成功率从 L1 的 80.0% 降到 L2 的 47.6%，L3 是 **0.0%**；对应的仿真成绩是 66.7%、47.6%、0.0%。反复出现的困难集中在空间推理、接触点选择、力调节和协调性上——作者的措辞是，局部的物理进展常常累积不成任务完成。

L3 全线挂零比那两个百分比更有信息量：它说明"协调地重构接触、同时调节力"这件事目前不是被部分解决了，而是根本没有被解决。这对能力评估的含义是，接触密集任务不该用一个总成功率来报，分层之后才看得见断崖在哪一级。

需要配一句克制的话：每个任务每个环境只有 3 次试验，所以"16 个任务里 10 个在两个环境下成功计数完全一致"这个 sim-real 一致性结论，统计效力很弱——3 次试验的置信区间宽到足以容纳不小的真实差异。这条该读作"物理与视觉匹配的仿真值得继续验证"，而不是"匹配仿真已被证明可以替代真机"。

## 8. 测试时适配该优化的不是预测误差

潜在世界模型通常离线预训练、测试时冻结，于是分布偏移下规划质量会退化。用 test-time adaptation 去救它，和常规预训练有一个结构性差别：这是**闭环**的——规划器用模型 rollout 选动作，产生的转移又驱动下一次更新。那么该用什么目标来指导这个更新？

[OpTTA](https://arxiv.org/abs/2610.35636) 指出，只用预测损失的话，模型只会去拟合自己已经走过的那些动作的结果，对"本来能到达目标的那些动作"可以一直是错的；而且预测误差低并不等于规划变好。借 adaptive control 里 reward-biased maximum likelihood 的思路，OpTTA 的目标加了第二项：除了已观测转移上的预测损失，还有规划器在候选 rollout 上的到达目标代价，两项都对模型参数最小化。这一项把适配偏向"对能否到达目标持乐观态度"的模型，而且不需要额外的环境交互。

在操作、reaching、导航任务的视觉与环境偏移下，只适配 predictor 时，OpTTA 比冻结模型平均高 13.5 个百分点，而只用预测损失的 AdaJEPA 是 6.9；连 encoder 一起适配时是 13.5 对 7.5。实验跨三个 JEPA 世界模型，以及 CEM 与梯度两种规划器。

这条线上多数工作在比"记忆容器用什么"——快权重、TTT 层、外挂缓存。OpTTA 不碰容器，碰的是适配的目标函数，并且指出了一个具体的失效模式：预测对了但规划还是错。实用的推论是，评估任何部署后自适应方案时，"预测误差下降"和"规划成功率上升"要分别报，因为这两个指标可以脱钩。

## 9. 第一人称数据迁移到人形，缺的两样东西都能补

把 VLA 扩到人形机器人上有两个硬成本：全身协调控制，和昂贵的真机示教。第一人称人类数据是一个天然的补充来源，但视觉本体不同、而且缺机器人本体感受，直接迁移不过去。

[HuGe](https://arxiv.org/abs/2610.34186) 的做法是让三种现有 VLA 架构都去预测供一个预训练全身控制器消费的**潜在运动 token**，外加手部控制信号，然后走三段式训练：第一人称预训练、人形适配、下游微调。两个针对性补丁值得注意——预训练期用仿真回放构造**伪本体感受状态**，下游微调期对第一人称观测里的**手臂外观做重渲染**。训练数据是 2000 小时以上的第一人称人类与机器人数据。

仿真基准 HumanoidArena 上取得 SOTA；真机在 Unitree G1 上，用视觉适配后的第一人称示教去增广机器人示教，pick-and-drop 的成功率显著提升。

这两个补丁的价值在于它们很具体："缺本体感受"用仿真回放补，"手臂长得不一样"用重渲染改外观，都是可以照着做的工程动作，而不是又一个新架构。不过真机结果只有一个 pick-and-drop 任务，结论强度有限。

## 10. 手机拍一拍，换掉真机示教

[Zero-HLM](https://arxiv.org/abs/2610.35075) 走 real-to-sim-to-real：把手机拍摄的场景和仿真里的源示教，变成人形 loco-manipulation 的训练数据。两个部件——Gaussian 引导的 agentic real-to-sim 重建负责把视觉与物理场景对齐；motion-environment 协同适配用 rollout 反馈去修正全身参考轨迹和交互几何。产出 4,800 条经过物理校验的示教，在三个 Unitree G1 任务上做零样本迁移。

数字是：仿真数据训练的 GR00T N1.7 拿到 66.7% 的平均完整任务成功率，而用真机数据训练是 46.7%。更值得看的是泛化配置上的那组对比——真机数据训出的基线策略汇总成功率 23%，扩大仿真训练后到 69%，且没有新增任何真机示教。

"手机拍一拍就能建出可训练的场景"是这里最有工程价值的主张，因为它把 real-to-sim 的门槛从专业扫描设备降到了手机。而 23% 到 69% 这个差距在说另一件事：真机数据稀缺的代价，在泛化维度上比在平均成功率上要大得多——只看平均成功率会低估这个代价。

## 11. 不训 VLA，用 harness 把 VLM 接到机器人上

[ZAP](https://arxiv.org/abs/2610.35817)（Zero-real Agent Policy）的路线和上面几条都不同：它不训 VLA，而是教一个小的现成视觉语言模型通过一套简单的工具 harness 去控制机器人。先用一个 27B 预训练模型打底世界理解与推理，再在简单仿真任务上做 SFT 和 GRPO 教它怎么动机器人。

训练期完全没有真机数据，真机任务上 96.7% 成功，在他们的 harness 里与一个前沿通用模型持平，而对比的一个 VLA 只有 33.3%；同时比那个前沿模型快 3 倍、便宜 17 倍。泛化演示包括把试管插进架子（被要求时换一个孔）、双臂空中传递试管、在井字棋盘上画 X、下国际象棋——这些目标与操作类型都不在训练数据里。还能迁移到没见过的本体：单臂 Franka 上 RoboLab-120 拿 55.9%，比最强 VLA/WAM 基线高 4.9 个百分点。

论文标题里那句"预训练知道是什么，仿真教怎么做"是对分工的一个明确主张，也是对"端到端 VLA 是唯一路线"的直接挑战。需要保留的怀疑有两点：成绩是在**他们自己的 harness** 里取得的，而 harness 本身承担了多少工作量，摘要没有拆开；以及"什么任务可以被 harness 化"有明显边界——演示的任务都偏离散步骤，高频力控类任务显然不在其中。

## 12. 用代码把单体策略改造成会检查、会重试的双系统

VLA 直接把指令和观测映射到动作，不检查指令有没有完成，所以长程任务里一步失败就会无声地让整个任务烂尾。[RoboDuo](https://arxiv.org/abs/2610.34108) 的切入点是两个可利用的事实：失败的 episode 往往已经部分完成；没做完的那些步骤，是在示教里反复出现的可复用原子技能。

于是它用**代码**作为 coding agent 与两个 VLA 之间的接口。agent 写一段程序，让全任务 VLA 去尝试整个任务并检查是否完成，失败时让原子 VLA 把剩下的步骤做完。因为 agent 自己不输出动作、只决定由哪个 VLA 执行，它可以包住一个现成的全任务 VLA 而完全不更新其权重。为了训原子 VLA 和具备完成判定能力的 coding agent，作者从**同一批** LIBERO 示教里构造了 LIBERO-Atomic、LIBERO-Code、LIBERO-Judge 三个数据集。X-VLA 和 π0.5 在 LIBERO 与 LIBERO-PRO 上都有提升，长程任务增益最大，真机上也能救回冻结全任务 VLA 的失败 rollout。

最有参考价值的不是双系统这个结构，而是那个数据构造方式：从已有示教里切出原子技能集和代码判定集，不采任何新数据，就能把一个单体策略改造成带完成检查与失败恢复的系统。这降低了"要不要做失败恢复"这件事的决策门槛。

另外几条差一点入选的，列出来备个案：[DiscoDemo](https://huggingface.co/papers/2610.32093) 把强化学习当数据生成器而不是可部署控制器，用 success-gated 的多样性目标去发现多种解法模式，下游真机成功率从 39% 提到 78%；[Video World Models Need Predictable Latents](https://arxiv.org/abs/2610.34663) 用时序表示目标配过去条件解码器，推理便宜 5 倍、训练快 7 倍、分布外与长程误差低 15 到 24%；[Behavioural Quality Is Not Learning Utility](https://arxiv.org/abs/2610.34839) 发现人类行为模型的生成质量指标不能一致预测下游策略表现，甚至按真实测试分布训练还不如按另一个分布训练；[ElevateHead](https://arxiv.org/abs/2610.34031) 让 action head 在学到的决策点上一次性选定模式并锁住，方法论写得相当诚实（每版冻结后在未见任务上测、预测先登记），但作者自报前四版在至少一个 held-out 任务上都不如基线，真机实验还只是计划中。
