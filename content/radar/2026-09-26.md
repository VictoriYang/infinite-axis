## 1. 离散动作 token 应该分开方向和尺度

**Direction-Scale Decomposition in Action Representation: Rethinking What to Tokenize for VLA Models** · [arXiv](https://arxiv.org/abs/2609.28865)

KTH（Danica Kragic 组）、哥本哈根大学、Stanford。离散 token 的 VLA 一直沿用一个做法：末端 pose 增量按每个数据集的均值方差归一化，再分箱。这篇指出三个问题。一是 token 对执行速度敏感，同一条轨迹遥操得快和慢会产生不同的 token 序列。二是同一物理位移在不同数据集的归一化统计下会落进不同 bin——作者拿 Bridge 与 VIOLA 的统计做了对比，256 bin 分箱对不上。三是迁移到目标本体时按目标统计反归一化，方向会被扭曲。

对策是把平移增量拆成「单位方向向量 + 模长」、旋转拆成「轴 + 角」，方向分量不过归一化，只归一化尺度通道，每臂 9 个标量。这个改动和 tokenizer 本身正交，作者在 BIN（直接分箱）和 BEAST（B 样条）两种 tokenizer 上都试了。LIBERO 平均 88.5 → 92.3。更能说明问题的是 SimplerEnv 上的五数据集 OXE 混训（bridgeV2、UR5、hydra、taco、viola，三种本体）：普通 BIN 从单数据集 40.0 掉到混训 33.0，DSD-BIN 从 40.7 涨到 43.3——同样的数据，加进去从掉点变成涨点。真机四个任务（叠方块、叠布、扫纸巾、换勺子）各 30 次，无预训练 +13.3、有预训练 +11.7。

这篇改变的是对混训掉点的归因。此前默认的解释是数据集之间动作分布或本体的冲突，对策是调配比、加 per-embodiment projector。这篇说有一部分掉点来自 per-dataset 归一化本身，修在 tokenizer 层就够了，而且和 projector 不冲突。

## 2. 部署后自适应：不更新权重，用自己的 rollout 当上下文

**Self-Adaptive VLA for Robust Robot Deployment** · [arXiv](https://arxiv.org/abs/2609.30092)

Chuang Gan 组（UMass Amherst / MIT-IBM），Zhenjia Xu、Tsun-Hsuan Wang 参与。针对的分布偏移很具体：硬件漂移——执行器偏置、关节编码器 offset、换工位。做法是一个后训练配方而不是新的架构层。训练时故意注入已知的硬件偏移采 rollout，把原训练数据里的专家动作按偏移**预补偿**成 shift-conditioned 示范；再加一个轻量 context encoder，把偏移环境下的观测、本体感知、动作压成一个 latent context token，经 AdaLN 调制策略主干。context token 可以在多条 rollout 上集成，策略能一步步自我修正。四个精度敏感的双臂 / 灵巧手任务上，硬件偏移下恢复基座策略 80% 以上的性能，换工位也比基座稳。

推理时适应这条线上，目前的参照系多是快权重或 TTT 层，要在部署时更新参数。这篇给出的是另一个容器：不更新权重，把自己的 rollout 当上下文喂回去。代价是只覆盖训练时注入过的偏移类型，好处是数据侧只需要「注入偏移 + 预补偿」，不改架构主干。对换工位、重标定这类工程问题，它是先于快权重该试的方案。

## 3. 策略恢复不了自己造成的偏差态

**RoboRecover: Benchmarking Robot Policy Recovery under Execution Deviations** · [arXiv](https://arxiv.org/abs/2609.28952)

人民大学 + 中科大。把「从执行中途的偏差态恢复」单独拿出来评：从轨迹里选偏差态，重放动作前缀把它复现出来，然后让策略从那里继续原任务。RoboTwin 和 LIBERO 各 1000 个场景（800/200 划分），四个阶段（接近 / 接触 / 移动 / 放置）× 四种偏差（错目标 / 错位姿 / 阶段回退 / 场景变化）。

三个结论。**初始态成功率不预测恢复率**：UnifoLM 在 LIBERO 初始态 98.8% 但恢复只有 48.0%，π0.5 初始态 94.2% 却恢复 64.4%。**策略恢复不了自己造成的偏差态**：RoboTwin 上源策略在自己产生的偏差态上只恢复 15–20%，别的策略在同一批状态上能恢复 58–70%。恢复率按阶段和偏差类型差异很大，单一总分说不清。训练划分还支持研究 Reversion（回退到偏差更小的状态）和 Correction 两种干预。

failure-recovery 数据的自生成，最省事的做法是同一策略跑出偏差态、再让它自己接着做。这个 benchmark 说那正是最差的组合——恢复示范应该来自别的策略或人。评测侧，凡是报单一成功率的 benchmark 都该单列一个 recovery 维度。它建在 RoboTwin 上，接入成本低。

## 4. action expert 的深度是一个独立的算力轴

**Decoupled Early Exits for Task-Dependent Compute Allocation in Flow-Matching VLAs** · [arXiv](https://arxiv.org/abs/2609.29382)

Politecnico di Milano + Edinburgh / Heriot-Watt（Ramamoorthy、Suglia）。现有给 flow-matching VLA 减算力的办法只动两处：backbone 早退，或减去噪步数。action expert 的深度从不碰。这篇把 backbone 深度 V、expert 深度 A、去噪步数 D 当成三个联调的轴：在两边的中间层挂轻量 Exit Transformer，蒸馏最后一层的输出；**KV cache synthesis** 补出被跳过的 backbone 层的 K/V，让 expert 可以比 backbone 退得更深——否则 expert 要读 backbone 的 KV，backbone 一退出 expert 就没得读。每个出口只增参 2.1%（SmolVLA）/ 4.1%（π0.5），不重训原策略。

SmolVLA 和 π0.5 在 LIBERO + Meta-World 上的结果：V 主要降 FLOPs，A 主要降延迟，D 两者都降；联调配置延迟 −79.2%、FLOPs −31.8%、平均成功率还 +5.6%。最优预算按任务不同。复现 π0 风格并行 expert 时，expert 层数通常默认对齐 backbone；这篇说它是独立轴且主要影响墙钟延迟，可以当超参搜。

## 5. 10 分钟人在环残差 RL 胜过 5 倍示范

**Res-HIL: Human-Guided Residual RL for Sample-Efficient Dexterous Manipulation** · [arXiv](https://arxiv.org/abs/2609.30023)

TUM（Majid Khadiv 组）。冻结模仿策略，在上面学一个零初始化的残差策略；每次人工干预给两个信号——残差的直接监督，以及对干预前自主行为的奖励塑形。五个接触密集任务（含高精度和长程），**20 条初始示范 + 10 分钟在线训练**，在每个任务上都超过全策略人在环 RL、无人干预的残差微调，也超过用 5 倍示范训的纯模仿策略。消融：残差直接监督决定性能，干预感知的奖励塑形主要提升效率。

人在环教学里，干预的直觉用法是「补 demo」——干预段落进数据集再训。这篇的算法结构说干预更大的价值是作为残差监督，而且不用重训整个策略。10 分钟胜过 5 倍 demo 这个比例值得在自己的平台上复现一次。

## 6. 人类第一人称示范当节奏参考

**EgoSpeedUp: Transferring Human Manipulation Tempo to Robot Policies** · [arXiv](https://arxiv.org/abs/2609.29310)

AIST（Takuma Yagi、Yukiyasu Domae）。模仿学习继承的不只是行为，还有遥操示范的保守节奏。这篇只拿人类第一人称示范做**时间监督**：把慢的机器人 demo 和人的 demo 按操作阶段对齐，从多条人类示范估计各阶段的相对节奏，然后对机器人 demo 做 phase-wise 重定时，再走标准 BC。两个真机任务成功率平均 +25pp，成功执行时间 −36.5%。

第一人称人类数据的常见用法是动作 / 手部姿态标注，需要和机器人动作空间对齐。这篇给了一个不需要动作对齐、不动模型的用法——当节奏参考。数据处理阶段就能做，对已有的遥操数据集是一次离线重定时。

## 7. WAM 的瓶颈从「能不能」转到「多快」

**Rolling-WAM: World Action Models with Rolling Imagination** · [arXiv](https://arxiv.org/abs/2609.30247)

Hao Dong（PKU）、Gaurav Sukhatme、Vitor Guizilini（TRI）、Yue Wang 等。同一天三篇都在解 WAM（视频 + 动作联合去噪）的延迟问题，取向不同。Rolling-WAM 维护一个错开噪声级别的滑动窗口：每步把最近的动作块完全去噪执行，远处的块只部分去噪，窗口随新观测前移，稳态重规划提速 4.5×，LIBERO / RoboTwin / 真机 Unitree G1 上性能持平。[Streaming-WAM](https://arxiv.org/abs/2609.28927)（SJTU）走异步执行：视频预测以「已提交的动作前缀」为条件，LIBERO 98.35%，真机盖章任务 90 s → 38 s。[DeltaWAM](https://arxiv.org/abs/2609.28811)（PKU Boxin Shi 组，有代码）改预测目标：只预测视觉 delta 而不是稠密帧，加 Streaming Delta Memory 更新缓存，RoboTwin 视觉随机化下 75.8 → 83.9，单步延迟 −36.6%。

三篇合起来的经验是：延迟可以从调度（Rolling）、执行时序（Streaming）和预测目标（Delta）三处分别削，互相不排斥。考虑视频预测做辅助监督的人，这三个开销数字是基线。

## 8. 「harness」从 agent 圈传到了具身

**HarnessPAI: An Evolving Harness for Physical AI** · [arXiv](https://arxiv.org/abs/2609.29166)

小米（Kun Shao、Jian Luan）等 23 位作者。本期池子里五篇论文标题带「harness」。共同结构：动作模型不动，外面套一层**代码形式**的协调层，rollout 内按程序开环执行、rollout 间用执行反馈改程序。HarnessPAI 的数字：π0.5 在 LIBERO-PRO 上 +61.6 点，RoboCasa 原子任务比 WorldDreamer +27.2；收敛后的程序不需要在线 LLM 推理；把它当专家数据采集器再微调 π0.5，LIBERO-PRO 再 +38.8。同期 [AdaHVLA](https://arxiv.org/abs/2609.29204)（UNC Tianlong Chen）把 harness 的修订做成带假设检验的多智能体流程，NaVILA-LH 22.5 → 57.5；[Robo-Harness K1](https://arxiv.org/abs/2609.29389) 把感知当工具暴露给 VLM，Gemini 3.7 Flash 在 LIBERO-PRO 77.8%；[RAPID](https://arxiv.org/abs/2609.30249)（MIT Kaelbling / Lozano-Pérez）从单条人类示范合成可验证的机器人程序，真机 Franka 八个非抓取任务。

判据要清楚：外挂一个程序化 planner 不等于把长程记忆做进了控制回路，它们不回答那个问题。价值在另一处——**收敛的 harness 是便宜的专家数据来源**，HarnessPAI 那段 +38.8 说的就是这个。

## 9. 在线 RL 微调 VLA 的「task collapse」

**Uncertainty-Gated Exploration Noise Suppresses Task Collapse in Online RL Fine-Tuning of a Flow-Matching VLA** · [arXiv](https://arxiv.org/abs/2609.28838)

两位独立作者，小算力预算下用 PPO + SDE 采样在线微调 SmolVLA（450M）做 LIBERO-10，报了一个失败模式「task collapse」：总分看着健康，单个任务的能力被毁掉。固定噪声三个种子塌两个，ReinFlow 式学习噪声每个种子都塌，不确定性门控的噪声控制器一个都没塌。但作者自己写明：**没有一个方案在这个预算下超过 BC 基线**；bf16 无 fp32 主副本时 96% 的 expert 参数三次迭代位级不变，而加了 fp32 主副本又两个方案都塌，这两点只报不归因。放了按四种定义测逐任务塌陷的工具。

机构和引用量都不高，收它是因为写法诚实。两条可带走的：在线 RL 后训练要看的指标不是总成功率而是逐任务；bf16 训练精度是个要提前排的坑。

## 10. 指尖触觉直接拼进策略可能低于纯视觉

**Self-Supervised Anchoring of Fingertip Sensing to Proprioception and Proactive Actions (PROPRA)** · [arXiv](https://arxiv.org/abs/2609.29822)

AIST。要点是一个负面观察：指尖触觉 + 接近传感器**直接拼进策略不一定涨，甚至低于纯视觉**——两种信号只在各自的阶段有信息（接近在接触前，触觉在接触后），稀疏且相位相关，少量示范学不出来。PROPRA 用本体感知和动作片段当持续可用的锚，分别对齐每个传感器的历史，预训练后真机任务平均成功率超过纯视觉和图像锚定的基线。正在采触觉数据的人，这篇预告了直接拼观测会遇到什么，锚定到本体感知的预训练是一个具体对策。

## 11. 1-bit 量化 VLA 掉多少（主动检索）

**HBVLA: Pushing 1-Bit Post-Training Quantization for VLA Models** · [arXiv](https://arxiv.org/abs/2602.13710) · 2026-02 发布

A*STAR / NUS（Yang You、Ivor Tsang）。本期不在时间窗内，是带着「量化对策略成功率的实测影响」这个问题搜出来的。1-bit 后训练量化：策略感知的 Hessian 挑关键权重，非关键权重做稀疏正交变换后在 Haar 域分组二值化。**OpenVLA-OFT 在 LIBERO 保留全精度的 92.2%，CogAct 在 SimplerEnv 保留 93.6%**，真机套件上「边际下降」，摘要未给具体数。论证的核心机制：VLA 是闭环，单步量化误差沿「观测 → 动作 → 环境 → 新观测」累积，所以评量化 VLA 要看长程任务成功率而不是单步动作误差。1-bit 下损 7–8 个百分点是当前的参考线。
