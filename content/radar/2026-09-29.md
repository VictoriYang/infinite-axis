## 1. VLA 的 RL 后训练更新集中在时间步调制模块上，LoRA 默认配置正好漏掉它

**The Low-Rank Structure of VLA Reinforcement Learning** · [arXiv](https://arxiv.org/abs/2609.34599)

首尔大学。系统测了 π0.5、GR00T N1.5 / N1.6、SmolVLA 在 LIBERO / ManiSkill / MetaWorld / CALVIN 上做 PPO 后训练前后的参数差。结论有两层：RL 的更新是低秩的；而且高度集中在 action expert 的 **Timestep Modules**——把去噪时间步映射成 scale / shift / gate 的 Time MLP 加 AdaRMS / AdaLayerNorm。这部分参数并不小（附录表 4：π0.5 里占 action expert 的 27.6%，GR00T N1.5 / N1.6 分别 14.8% / 16.5%），但标准 LoRA 配置一律不挂在它上面。模块替换实验显示只换这些模块就能拿到 RL 收益中不成比例的大头；把 LoRA 只打在 Timestep Modules 上比标准 LoRA 配置更好。

原因也讲清了：BC 阶段在连续 t∈[0,1] 上训练，而 on-policy RL 只在 rollout 实际用到的那几个离散去噪步上训练，模块因此对离散时间步特化，形成低秩结构。图像 / 视频生成的 flow 模型做 RL 没有这种现象，是动作策略特有的。附带一个漂亮的诊断结果：shift 向量的更新方向能以 ROC-AUC 99.6% 预测任务成功，沿这个方向 steering 还能进一步提分。

这篇改变的是对「VLA 的 RL 后训练在动哪里」的预期。此前的默认假设是它和 LLM 一样，更新散在 attention / FFN 投影里，LoRA 照 LLM 的目标挂就行。这组实验之后，对 flow-matching 类 VLA 做 RL 后训练，时间步调制模块该是首要目标——先只训它们做基线，再决定要不要开更多参数。另外「BC 连续采样 t、部署固定 N 步」这个分布差本身是一个可利用的空隙，值得在自己的复现里量一下。

## 2. 记忆该按类型分两处：策略内留感知记忆，策略外做物体 ledger

**Where Memory Belongs: Ledger, an Object Ledger for Memory-Augmented VLAs** · [arXiv](https://arxiv.org/abs/2609.34554)

Harvard（Heng Yang 组）+ ETH。出发点是 RoboMME 上的一个数字：同一个 π0.5 backbone、同一份示教，最好的策略内记忆机制远低于「由 oracle 直接给出正确目标」的成功率。也就是说瓶颈是「该对哪个东西动手」没解析出来，不是底层执行。

于是把记忆按类型拆开。**短期感知记忆**（做了几次、走过哪里、示教动作长什么样）留在策略内，用帧采样调制；**长期物体记忆**（哪个物体现在在哪、被什么盖住、事件顺序）放在策略外，做成一个可读的 ledger——SAM3 跟踪每个物体的静止区间和遮挡事件，VLM 转写示教视频。LLM planner 在每个步骤边界读 ledger，决定是给策略一个坐标目标、还是交给策略自己的记忆（空 subgoal）。单套 π0.5 权重在 RoboMME 四个 suite 平均 64.3%（此前最强 45.9%），object reference 60.7% vs 40.3%，object permanence 86.7% vs 56.2%。

消融里最有意思的是**记忆源是任务相关的**：计数和模仿类任务给坐标目标反而不帮忙甚至掉分（MoveCube 掉 15 点），空间类任务只要跟踪器就够，只有 reference 类必须靠 ledger。

这篇改变的是对长程记忆方向的判断。此前的主流思路是把更长的观测历史塞进策略——更大的上下文窗口、递归状态。这组消融之后，更合理的拆法是：「物体去哪了」这类持久状态从策略里拿出来做成外部可读记录，只把重复 / 计时 / 动作模式这类感知记忆留给策略；而且 planner 决定用哪种记忆应该在运行时按指令判断，不该提前按任务类型路由。它直接回答了「长程任务里记忆该存什么」这个问题——不是一个统一的记忆模块，而是按「世界做了什么」和「机器人刚做了什么」分两处。

## 3. 跨本体对齐的第三条轴：物体运动而不是末端运动

**UMR: Universal Manipulation Representation** · [arXiv](https://arxiv.org/abs/2609.34256)

中科大 + 苏州 AI 实验室。跨本体动作表示的现有做法在关节空间和末端空间里二选一，这篇提出第三条轴：把同一段操作拆成两个几何上绑在一起的分量——**World Flow**（世界坐标系下与本体无关的物体运动）和 **Ego Trajectory**（末端相对当前位姿的运动），两者靠 SE(3) 共轭耦合，是同一运动的两个坐标视图。0.5B 的 WEPVLA 用点云输入、双流 Point Action Adapter 加共享 Point Action Expert 联合去噪两个流，推理时只执行 Ego Trajectory。配套的 DES 做阶段感知的点云编辑，保留示教里的接触几何来扩样。LIBERO 97.5%、RLBench 10 任务 85.7%；真机上**每任务约 10 分钟人类示教、零机器人示教**，六个评测设置平均 91.7%。

它和 per-embodiment projector 的差别在于把「本体无关」的部分定义成物体运动而不是末端运动，人类示教和机器人示教在 World Flow 上天然对齐。第一人称人手数据如果按这个表示标注，可以直接混进机器人数据。局限也明确：依赖固定的物体—末端附着假设，非抓握式操作没覆盖。

## 4. 把动作 tokenization 从压缩问题改成因果生成过程

**CATok: Rethinking Causal Action Tokenization with Conditional Annealing in Flow Matching** · [arXiv](https://arxiv.org/abs/2609.35469)

清华（赵行组）等。批评现有动作 tokenizer 把 tokenization 当压缩问题，产出的 token 和自回归 backbone 的语义不对齐。CATok 把 tokenization 改成因果生成过程：逐步退火一个 flow-matching 过程，每个 token 条件于前面所有 token、编码特定噪声水平下的残差重建信号，形成粗到细的因果 token 空间。解码端是 MMDiT 上的 token 条件 flow-matching decoder，把离散 token 还原成连续动作块。离散瓶颈天然做到 knowledge insulation，不需要注意力 mask。三个仿真基准加真机，重建保真—压缩率、推理效率、任务成功率、训练效率都优于已有 tokenizer。

对走纯自回归 VLA 路线的人，这是把 FAST 那类频域压缩换成「和自回归结构对齐」的 tokenizer 的一个方案，值得加进 tokenizer 对比。

## 5. 推理加速一：滚动去噪 + 解耦 VLM 上下文

**RAVEL: Asynchronous Rolling Inference for Flow-Based VLA Models** · [arXiv](https://arxiv.org/abs/2609.34170)

浙大。同时拆两个瓶颈。多步去噪的延迟靠**滚动缓冲**解决——近期动作只需一步去噪就能执行，部分去噪的未来动作在缓冲里滚动向前继续精炼。VLM 编码慢的问题靠**解耦**——action expert 用最近一次可用的 VLM 上下文持续跑，再加一条轻量的 Fast Observation Pathway 让 action expert 直接看到当前观测。仿真和真机上响应延迟显著下降，任务能力和原 VLA 持平。

它把「VLM 上下文可以旧一点、观测必须新」这个假设做进了架构，和 KV cache 复用正交，可以叠加。

## 6. 推理加速二：动作块的尾巴别扔，速度平滑就接着执行

**Don't Throw Away the Tail: Action Upcycling for Policy Acceleration** · [arXiv](https://arxiv.org/abs/2609.34911)

KAIST（Jong Chul Ye 组）。观察很简单：策略预测一个动作块、只执行前缀、其余丢掉；而被丢掉的动作和下次重规划的版本其实很接近——**只要动作速度保持平滑**。所以训练无关地把执行地平线延长到速度开始波动的那一点。不读模型内部、不多采样，对任何分块策略都适用。多个 VLA 和一个世界动作模型上策略调用次数减少 1.2–1.7×，成功率不掉；和少步采样、流式解码正交。

比 RAVEL 便宜得多的一个加速项，可以直接加在现有部署上。「速度平滑度」作为执行地平线的判据，也可以反过来拿去当数据质量的一个信号。

## 7. 失败驱动一：把真机失败重建到仿真里再 RL

**F4R: Failure-Driven Recognition, Reconstruction, Refinement, and Redeployment** · [arXiv](https://arxiv.org/abs/2609.35575)

闭环是：真机失败 → 自动诊断 → 把失败重建成保留任务相关空间和物理条件的物体中心桌面仿真环境 → 失败条件下的 sim-real 共训加重建环境里的定向 RL → 重新部署，新失败进入下一轮。四个真机操作任务上 ID 93.75% / OOD 90.0%，比预算匹配的 Targeted BC 在 OOD 上高 18.75 点，**不额外采集真机纠正示教**。

它把「失败数据从哪来」的答案换成「失败场景重建到仿真里再 RL」，绕开了人在环纠正的采集成本。摘要没给迭代轮数和饱和点，「数据飞轮转了几轮、什么时候饱和」这个问题它还是没答。

## 8. 失败驱动二：失败轨迹只用来学「什么时候不可靠」

**FailPatch: Failure Residual Patching for VLA Models** · [arXiv](https://arxiv.org/abs/2609.34175)

西交（与 F4R 有共同作者）。另一条处理部署失败的路：成功示教负责「该怎么做」，部署轨迹只负责「什么时候不可靠」。观察到冻结 VLA 的动作隐表示在可靠状态和失败相关状态之间线性可分，于是在动作隐空间里加一个 Null-gated 残差专家库，Preserve–Redirect–Trust 目标在可靠状态保留原策略、在失败状态选残差专家把表示推回成功区域。只训 0.52% 参数，RoboTwin 四个长程任务 +11.0 点，clean-to-random +9.5，三个真机任务 +16.7。

和 F4R 相比它不需要重建环境，失败轨迹本身就是监督信号。两篇合起来看，这个组在把「失败数据没有纠正动作」这个老问题拆成两种用法。

## 9. 触觉作为跨本体的对齐锚，人类示教千条仍未饱和

**Unified Visual-Tactile-Action Modeling from Human Demonstrations** · [arXiv](https://arxiv.org/abs/2609.34182)

BIGAI / 清华。前提是「手可以换，接触物理不变」。做了一套触觉动捕系统同步记录图像、触觉、手部运动，采了 UVTA 数据集：五个接触密集任务，每任务 1000 条人类示教加 150 条机器人示教。模型把两种本体映射到对齐的触觉与动作表示，联合预测未来动作和触觉轨迹；人类示教只用来监督接触感知的表示，部署时只执行机器人动作。五个真机任务平均 70%（最强视触基线 29%，架构消融 42%）。**人类示教加到 1000 条/任务仍未饱和。**

它说明手套的触觉通道不是附属信息，可以作为跨本体的对齐锚；而「每任务千条级」是采集规划里一个可参照的量级。

## 10. 评测缺口一：相机中途断流

**Learning to Act under Visual Interruptions with VLA Models（MAIL-Bench / MINT）** · [arXiv](https://arxiv.org/abs/2609.35003)

悉尼大学。相机中途断流是真机上常见、论文里几乎不评的失效模式。MAIL-Bench 在每个策略的成功参考轨迹的不同阶段切断不同相机，测能力保留多少。MINT 先训策略在缺失视角下能继续工作，推理时用光流外推或动作条件世界模型有选择地补视角，不可靠时撤回。π0.5 和 GR00T N1.5 上相机丢失时成功率显著提升；AgiBot G2 真机验证。

多相机 VLA 的评测协议里应该加一项「断一路相机」，它和 LIBERO-Plus 那类视觉扰动测的是不同东西。

## 11. 评测缺口二：隐式指代，换更强 VLM 也不解决

**RoboIRG-Bench: Implicit Referential Grounding in VLA Models** · [arXiv](https://arxiv.org/abs/2609.34384)

复旦。指令里不明说目标物（「把刚才那个」「多拿一个」「左边那个」），策略得从语言和感知上下文里恢复指代。基于 RoboMME 建 11 任务 40 变体，覆盖直接 / 推理中介 / 空间 / 上下文四类指代。显式指令下表现好的模型在隐式指代下急剧退化；用外部 VLM 的更稳但仍大量失败，**换更强的 VLM 也不消除这个差距**；Franka Research 3 真机上差距持续存在。

「换更强 VLM 不解决」这一点值得记，说明这类失败不在语言理解侧。和第 2 条的 Ledger 一起读：两篇用同一个 RoboMME，一个说明问题、一个给出记忆侧的解法。

## 12. 主动检索：记忆类基准的长地平线尺度

**RoboMemArena: A Comprehensive and Challenging Robotic Memory Benchmark** · [arXiv](https://arxiv.org/abs/2605.10921) · 2026-05

港科广 / 西湖（王东林）等。26 个任务，平均轨迹超过 1000 步，68.9% 的子任务依赖记忆；VLM 设计并组合子任务、原子函数生成完整轨迹、带子任务指令与关键帧标注，配对真机任务。附带 PrediMem：高层 VLM planner 管一个 recent + keyframe 双缓冲记忆库，加预测编码头。Ledger 的相关工作里引了它的一个结果：千步以上地平线时冻结 VLM planner 的成功率坍塌。本期只读了摘要，具体消融数字没拿到。

和 RoboMME 一起构成记忆类基准的两个尺度：RoboMME 按四类记忆分，RoboMemArena 拉长地平线。

### 差一点入选

- **Do Not Cut When Uncertain: Rejectable and Calibrated Decision Heads**（[2609.35039](https://arxiv.org/abs/2609.35039)）——「VLA 的失效模式由输出接口决定而不是 backbone 规模」，给冻结 VLA 换一个带拒绝选项的输出头就恢复了遮挡下的可用性。反直觉且便宜，但单作者、只在采摘平台上验证。
- **Spatial Grafting**（[2609.35249](https://arxiv.org/abs/2609.35249)）——把冻结的 3D 重建特征绑定到机器人相对的度量几何，cross-attention 注进 flow-matching action expert；RoboTwin 2.0 上 π0.5 +11.3 / +15.6。属于「又一个 3D 条件化」。
- **Holo-M: Humanoid Loco-Manipulation With Discrete VLA**（[2609.35709](https://arxiv.org/abs/2609.35709)）——按身体部位拆四个 tokenizer 扩展 LM 词表，分组离散扩散解码而不是自回归。只在 SIMPLE 仿真基准上。
- **Gaze Prompts**（[2609.34550](https://arxiv.org/abs/2609.34550)）——VR 遥操作时记录眼动，训练时把注视点画成十字准星贴在头部相机图像上，部署时用轻量预测器生成同样的提示；π0 六个真机双臂任务 26.3% → 56.0%。数据采集侧的想法。
- **WB-WAM**（[2609.34199](https://arxiv.org/abs/2609.34199)）——1880 小时部分标注的视频与动作数据做全身动作监督的视频预训练。人形方向。
