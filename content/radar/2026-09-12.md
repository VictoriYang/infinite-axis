## 本期主线：长程任务的记忆该放在哪一层

机器人基础模型普遍是马尔可夫式的——只吃当前观测。但很多真实任务本质上非马尔可夫：瓶颈常常不是策略不会做，而是**记不住做到哪一步了**。既有做法无非是语言摘要、逐渐变长的视觉窗口、或者给策略加循环状态。

本期一天之内进来三篇，给出的是三种互斥的答案。有意思的是效果最好的那个，把记忆完全移出了执行器。

### 1. 2AM：记忆可以整个留在 Agent 侧，执行器无状态

[论文](https://arxiv.org/abs/2609.11308)

作者先指出了这类研究的一个方法论问题：当前的智能体系统习惯把 VLA、规划器、几何工具堆在一起，有时还额外用深度或标定好的几何。这种堆叠**让归因变得不可能**——涨分可能来自更丰富的观测，也可能来自替代的运动工具；失败可能来自策略本身，也可能来自语言接口没把意图说清。

2AM 用一个刻意受限的设计把变量掐死：**工具更少，但接口带宽更大**。多模态 Agent 是任务记忆的唯一持有者；动作模型是一个 episode 内完全无状态、纯 RGB 的执行器。两者之间只有 Agent 编译出的子任务语言，加上可选的 2D 抓取、放置、移动提示——这些提示把 Agent 的物理意图绑定在不同的时间尺度上。为了让 VLA 吃得下这种指挥，训练时用结构化提示标签增广演示，并施加条件 dropout、空间噪声和时间抖动，以容忍 Agent 输出不准。

在 LIBERO-Mem 上，不用深度、不用在线几何、不用规划器驱动物体运动，平均完成度 **76.3%**，而此前报告的最强基线是 14.8%——高出 61.5 个点（宽松成功率 63.0%，严格成功率 11.8%）。

这个幅度改变的判断是：**长程任务的记忆并不必须做进策略**。此前的默认反应是加长上下文窗口或给策略加循环状态，而这篇说明把记忆整个搬到 Agent 侧、让执行器彻底无状态，反而能work。它进一步提出了一个此前没被当作独立变量的东西——**接口带宽**：动作模型的能力上限不只取决于它学到了什么，还取决于 Agent 能多精确地指挥它。碰到长程任务失败，先做「记忆放在哪一层」的消融，比直接加长上下文更有信息量。

### 2. MaP-WAM：记忆只在规划时刻用，执行器上下文定长

[论文](https://arxiv.org/abs/2609.11561)

第二种答案。既有记忆机制要么丢掉细粒度视觉证据（语言摘要），要么在「历史覆盖」和「执行效率」之间二选一（越来越长的视觉窗口）。MaP-WAM 的做法是不反复用完整历史去条件化执行器，而是**把长期多模态情节上下文当作规划时刻的证据**。

记忆被表示成「已完成片段记录」，含语言指令和稀疏视觉上下文；再压缩成一个紧凑计划——下一段的片段级语言计划加对应的视觉引导。执行侧是一个 World-Action-Progress 模型，在推理时联合预测动作 chunk 和执行进度，并通过「计划-观测对齐」校准预测进度，以此决定何时切换片段并闭环更新上下文。RMBench 上 83.3% 成功率（当前最好），真机任务 78.0%。

真正值得记的是它的工程性质而非分数：**执行器上下文长度固定**，加上结构化注意力让规划和执行两侧都能做 KV cache，于是任务历史变长时执行器推理延迟近似不变。这说明「历史覆盖 vs 执行效率」这个权衡并不是记忆机制的固有代价，而是可以整体挪到规划侧去付账。做长程任务的延迟预算时，按「执行器上下文定长、可变长度那部分放进一个低频规划环」来立，会比按「历史越长越慢」来立更合理。

### 3. UniMPA：记忆做进模型内部，而且是检索式的

[论文](https://arxiv.org/abs/2609.11875)

第三种答案，和前两篇最对立。它把观测到动作的困难拆成三个耦合问题：**转移歧义**（视觉上相似的观测其实处在不同的操作阶段，隐含不同的后续转移）、**预测-执行错配**（视觉上合理的预测未来不等于物理上可实现的转移）、**经验-实现错配**（历史上能跑通的动作模式在当前场景不一定能实现意图）。

机制上一一对应：一个持续的隐状态流跟踪任务级进度，加一个「转移关键像素」流做细粒度交互变化的预测；预测出的转移去查询一个时序 Visual-Action Memory Bank，用历史上**真正实现过**的视觉-动作经验为未来预测背书；再由 Action-Visual Memory Bank 取出视觉锚定的动作原型，用 Prototype-Biased Flow 把 flow 的源头推向历史上支持过的动作流形。

需要说明：拿到的摘要截断在方法描述处，**没有实验数字，所以效果无法判断**。收录它是因为那个检索判据本身比它的实现更值得记住——它拿「物理可实现性」而不是「视觉合理性」当作记忆检索的门槛。这一点和前两篇不冲突，反而可以叠加。

三篇放在一起看，结论不是「哪种记忆最好」，而是**记忆的位置本身是一个尚未被系统消融过的设计维度**，且它对成败的影响可能大于记忆容量。

## 4. IMLE-VLA：单步 action head 打掉多步采样，而且没牺牲泛化

[论文](https://arxiv.org/abs/2609.10915) · [项目页](https://kianhk6.github.io/IMLE-VLA/)

主流 VLA 设计是预训练视觉-语言骨干加一个专用的连续动作头，用 diffusion 或 flow matching 训练。但这类头依赖迭代式多步采样（比如 π0.5 的 10 步 Euler），构成推理瓶颈，表现为机器人**停顿-启动式的运动**和更慢的任务完成。

IMLE-VLA 把迭代式动作头换成一个单步条件生成器，用 conditional Implicit Maximum Likelihood Estimation（cIMLE）训练。关键在于 cIMLE 目标本身就鼓励多模态动作覆盖，因此既避开了朴素回归头的 mode collapse，又彻底取消了多步采样。

装到 π0.5 上，推理频率从 15 Hz 提到 55 Hz（3.67 倍），动作吞吐最高 11 倍。LIBERO 40 任务平均成功率 98.0%，是所有基线中最高。真机 Franka Panda 四个任务全面超过 π0.5，jerk 降到原来的 1/2.2 到 1/3，单 episode 平均推理时间降到 1/3.9 到 1/6.6。

最关键的一项是鲁棒性：在 LIBERO-plus 的测试时扰动下，IMLE-VLA 保住了 π0.5 的鲁棒性，而其他基线明显退化。这直接反驳了一个常见预期——多步采样是换取动作多模态性的必要成本，提速只能靠蒸馏或减步数，并且要接受一定泛化损失。把多模态性放进训练目标本身之后，单步生成可以同时拿到最高分和不退化的鲁棒性。对于正在选型 action head 的人，这意味着「先上 flow matching、之后再想办法减步数」不该继续当默认路径，单步生成式目标值得作为并列候选先跑一遍基线。

## 5. SEED-UMI：让人和机器人戴同一副外骨骼

[论文](https://arxiv.org/abs/2609.11753)

灵巧手的模仿学习卡在采集上：接触密集的演示很难采，采到了也很难忠实迁移到机器人。此前的可穿戴外骨骼方案有一个具体的失效点——**只在人这一侧记录**，再用在自由空间里标定出来的开环映射做 retarget，而这种映射**一接触就退化**。

SEED-UMI 的做法是让人和机器人戴同一副外骨骼。两个后果：关节编码器成为一个物理上共享的测量量；装在外骨骼上的腕部相机在人采数据和机器人 rollout 时观察到的是同一套外部机构。于是 retargeting 从开环映射变成了**成对的跨本体监督**，策略可以直接在原始的「外骨骼视角」腕部图像上训练，**不需要分割也不需要 inpainting**。五个接触密集任务上，数据采集效率是基于外骨骼遥操作的 3.0 倍，平均 rollout 成功率 70.0%。

这条改变的是无本体式人手采集（UMI 那一路）的工程重心。此前的假设是主要负担在视觉侧：要把人手从腕部图像里分割或 inpaint 掉，以消除人与机器人之间的视觉 gap。共享机构让这个 gap 直接不存在，整个分割/inpainting 环节可以删掉；同时 retargeting 误差从一个标定出来的固定映射变成了有监督可学的量。采集硬件设计上，「能不能让两侧共享同一段机构」是个应该先问的问题，再谈软件侧补偿。

## 6. ReactHuman：四类失败模式，没有一类随模型规模缩小

[论文](https://arxiv.org/abs/2609.10895) · [数据集](https://huggingface.co/datasets/Alan123/reacthuman-benchmark-scaled)

对突发物理危险的反应——接住滑落的盘子、躲开掉下来的刀——既是具身智能的一项有意义的测试，也是把多模态大模型当作家用机器人决策核心的硬要求。但现有评测要么用视频问答被动地考察直觉物理，要么面向导航、重排这类深思熟虑的长程任务，**没有一个测量模型能否把物理理解转化为即时的、安全关键的动作**。

ReactHuman 让被评测的模型直接充当一个仿真人形机器人的大脑。17 个事件族、1000 多个逐位可复现的场景，精确真值来自 240 Hz 刚体仿真且无需标注，其中专门包含**外观与物理相矛盾的对抗物体**（泡沫做的砧、钢做的苹果）。五项指标沿「合理、安全、物理可信」三个轴打分。关键设计是每个被提交的计划都会被真正执行，因此决策有可观测的后果。

七个代表性模型的结果值得原样记住：大约每三个危险就误处理一个；行动出自固定的倾向而非观测到的场景；信外观不信运动；即使选对了动作，拦截点也会差到米级。**这四类失败没有一类随模型规模缩小。**

后半句是这篇最有价值的部分。如果直觉物理的短板只是「物理知识不够」，规模和数据增长应当能缓解；但四类失败都不随规模缩小，而其中两类——按固定倾向行动、信外观不信运动——本质上是**不看当前观测、不用运动信息**，属于条件化失败而非知识失败。这对评测设计有直接含义：只报总成功率会把这两类掩盖掉，需要单独测「同一场景下把物体外观与物理属性解耦后模型是否改判」以及「决策是否随观测变化」。

## 7. 手内写字：不建模、不学习、笔记本 CPU、18 秒起步

[论文](https://arxiv.org/abs/2609.11775)

用拟人手对已抓持物体做手内操作，是机器人灵巧性尚未解决的前沿。接触丰富且高度动态的手-物交互，通常要求大量建模或数据采集：现代仿真器无法完全复现所需的接触复杂度，而采集灵巧演示本身仍是开放问题。

这篇给的是另一条路：在物理机器人上**在线估计「手 + 物体」这个合体系统的任务 Jacobian**，直接做控制。没有解析的手-物体运动学/接触模型，没有仿真训练，没有预采集的演示；只用一台笔记本的 CPU，约 18 秒初始化之后开始手内握笔写字，并持续在线适应。同一套估计器/控制器公式在三套拟人手上成立（一套实物、两套仿真），公式与本体无关。实物上在空中和纸上写字母与形状，平面内平均精度 0.6 mm。作者称这是拟人手第一次通过纯手内运动、握着笔写出任意单笔画轨迹。

它的价值在于当了一个便宜的反例。手内操作的瓶颈被普遍归结为接触建模太难、必须用强化学习在仿真里堆量或用模仿学习堆演示来绕过建模。这篇说明至少对一类任务——握持物体的精细手内 articulation——可以既不建模也不学习。任何要投入仿真 RL 或大规模演示采集的灵巧手计划，都值得先花一两天跑一下这条极便宜的基线。另一个推论是：「本体无关」有时可以由控制公式直接提供，不必都压在学到的统一动作表示上。

## 8. ActSafeGuard：把硬约束接进 flow 的训练，而不是套在外面

[论文](https://arxiv.org/abs/2609.11697)

VLA 与世界-动作模型在通用操作上已经很强，但它们生成的动作可能违反硬物理约束，因而在部署时不安全或不可行。既有的安全方案有两种错位：一种优化统计意义上的安全目标，**给不出每一步的确定性保证**；另一种只在推理时纠正不安全动作，于是**训练与执行之间存在错配**。

ActSafeGuard 是给 flow matching 类策略加的一个可微、且与训练对齐的安全层。它把硬动作可行性整合进策略学习本身，而不是把安全当成推理时的外部组件。通过一个解析的 ray-scaling 算子设计，边界感知的梯度得以引导模型自然地学到受约束的流形。在 π0.5 和 Fast-WAM 两个基座、多类任务上，逐步安全率稳定 100%，同时任务成功率完全保持甚至略有提升。

对做 flow matching 动作头的人，这提供了「硬约束进训练」的一条最小侵入式实现路径——不是在动作头外面套一个投影，而是把可行性的梯度接进 flow 的学习过程里。

## 9. Topological Necessities：跨本体对齐的第三条轴

[论文](https://arxiv.org/abs/2609.11014)

长程目标条件强化学习通常把控制交给一个提子目标的高层模块，但既有的子目标都是价值函数或隐动作的隐式副产品，**和产生它们的那个执行器绑死**。

这篇研究的是另一种对象：一个路线条件化的、不可回避的阶段顺序——每个成功的执行器都必须经过它，且它不属于其中任何一条轨迹，可以从离线轨迹里恢复。它的定义性质是拓扑的：不可跳过的阶段是一个分离集（任何可行路径都必须穿过它），自由空间里的一个环则强制一次路线选择。作者用成功轨迹搭出的传输加权载体上的 0 维和 1 维同调来读出这两者，得到一个可枚举、带 shell 级证书的 gate 集合，再作为递归的拓扑门层级进入决策回路。

在自由空间固定且同构的前提下，这个对象能扛住执行器替换：在 PointMaze 数据上冻结的 gate 无需重训就迁移到 Ant 和 Humanoid，统一接口下 Humanoid 总分最高（96.1），多路线任务上比一个有地图特权的参照高出 36.0 个点（p=1.4e-5）；PointMaze 饱和（100±0），AntMaze（giant +22.9）与 Kitchen（+15.8/+12.6）持平或超过最强基线。

跨本体的既有做法——per-embodiment projector、动作 tokenizer——都在赌「不同机器人的动作空间可以对齐」。这篇提出的是**第三条对齐轴**：不在关节空间，也不在末端空间，而在任务拓扑。需要提醒的是这是 maze 与 locomotion 设定、不是操作任务，且依赖「自由空间固定且同构」这个不弱的前提，不能直接套到桌面操作上。

## 10. 一个基准分数可以主要属于 harness，而不属于模型

[报道原文](https://mp.weixin.qq.com/s?__biz=MzI3MTA0MTk1MA==&mid=2652725028&idx=2&sn=fb813584fd0cdb605249a20166fe92a1)

**这一条的具体数字未经独立核实，以报道为准。** 收录它是因为争议的机制可以旁证，且该机制对读任何基准分数都适用。

据该报道：OpenAI 在 GPT-6 Astra 的发布页写明其在 ARC-AGI-3 上取得 99.9%、「饱和」了这个基准。出题的 ARC Prize 基金会当天发文拒签，指出该分数来自 OpenAI 定制的测试环境；换成对所有厂商一视同仁的标准环境，最高分只有 62.7%，而成本反而从约 1.9 万美元升到 2.6 万美元。基金会的结论是「泛化上有实质进展，但我们不宣称它是 AGI」。同榜 Claude Opus 5 为 30.2%、GPT-5.6 Sol 为 7.8%。报道也提到基金会承认了阶跃式进展：在 96% 的关卡里，该模型用的动作数比人类还少，平均少 51.7%。

机制这一层有旁证：另有报道说明 ARC-AGI-3 刻意采用统一的 harness（运行时框架）以保证跨模型可比，而官方 harness 在每次行动之后**不保留模型此前生成的内部推理状态**——模型能看到过去的行动记录，却访问不到支撑这些行动的思考过程。定制环境补上的恰好是这一点。

值得记的判断是：一个基准分数的可比性，此前主要被认为取决于测试集和指标是否一致，harness 算实现细节。这件事说明 harness 可以是分数的主要来源，同一模型同一基准差出 37 个点。对具身评测同样适用——看到任何成功率数字时应当多问一句「harness 是谁的、是否保留了跨步的内部状态」；自己报数时也应当把定制环境与标准环境的两套分数分开标注，否则不可比。

## 附：本期主动检索为何全部零命中

雷达的常规源都是时间锚定的，只回答「最近 48 小时出了什么」。另有一层是问题锚定的：带着固定的问题去搜，不限发布时间。本轮轮换到的三条问题是「有没有实证支撑的『其实不需要某个默认组件』」、「推理时学习在具身侧的进展」、「长程任务里的记忆」。三条各做中英两次检索，检索词均不带年份与「最新」，**全部零命中**（判据是「它回答了这个问题」，而非「它提到了这些词」）。

- **其实不需要 X**：英文检索返回的全是已经熟知的旧基线（learning-from-scratch 基线、预训练数据集的无偏对比、diffusion policy 的编码器消融），没有新的「去掉某个默认组件、性能不掉」的实证。中文检索这一轮没有返回有效结果。
- **推理时学习**：检索出的跨本体工作全部停在离线/预训练阶段，不涉及部署后的测试时更新；在线学习那一侧的命中是高斯过程模型学习与四足步态在线调参，量级和容器都对不上。没有一条回答跨本体下测试时训练层是否成立、wall-clock 延迟实测、或超长上下文下的遗忘行为。
- **长程任务里的记忆**：英文检索被大模型持续学习的「灾难性遗忘」整块劫持——那是权重层面的知识丢失，与 episode 内的进度丢失是两回事。唯一沾边的是一篇主张机器人需要情节记忆的立场论文，但既没有把记忆做进控制回路，也没有量化「记不住」占失败率多少。中文检索完全跑偏到了股票交易策略。

有意思的是第三条问题的答案今天恰好由时间锚定的源给满了——本期前三条正好命中它判据里的两项。也就是说零命中不说明问题过时，而是**检索词够不着自己的问题**：中文里的「长程」「回路」「操作策略」会被金融语料劫持，英文里的 forgetting 会被大模型持续学习劫持。这两处是检索词的缺陷而非问题的缺陷，该换的是词表（例如改用 repeated subtask、skipped step、progress estimation），不是换问题。前两条问题连续多轮没有新东西，需要单独观察。
