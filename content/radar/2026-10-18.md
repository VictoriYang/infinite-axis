## 1. ASPIRE v1.0：机器人的「持续学习」可以不碰权重

[GitHub](https://github.com/nvlabs/aspire) · [arXiv 2607.00272](https://arxiv.org/abs/2607.00272) · NVIDIA GEAR、密歇根、UIUC、伯克利、CMU（Linxi Fan、Yuke Zhu、Ken Goldberg、Guanya Shi 等）

ASPIRE 6 月就挂了论文，这周放出 v1.0 开源。它走的是 code-as-policy 路线：一个 LLM 编码智能体给机器人写控制程序；闭环执行引擎把每次执行的细粒度多模态 trace 交还给它，让它自己诊断失败、合成修复、再验证；验证过的修复被蒸馏进一个**持续扩张的技能库**——就是一个代码仓库；最外层再用进化搜索生成新的任务序列和程序变体去探索。README 的说法很直白：「训练」是技能精炼而不是梯度下降，「训练出的模型」是一个传感运动技能仓库而不是一堆浮点权重，「分布式训练」是一组各自练不同技能的智能体。

6 月版论文的数字：LIBERO-Pro 扰动设置下比先前方法高最多 77%，Robosuite 双臂交接高 72%，BEHAVIOR-1K 长程家务高 32%；积累下来的技能库还能零样本迁移到没见过的 LIBERO-Pro Long 任务，31% 对先前方法的 4%（后者还用了测试时推理和重试）。

v1.0 的增量几乎全在**换后端模型**上。同一套框架、10 个 LIBERO-Pro 任务，成功率从 15%（GPT-6 Luna 当后端）一路到 99%（Claude Opus 5.5）；Opus 5.5 在 LIBERO-Pro、Robosuite、BEHAVIOR-1K 每个任务上都是 97–100%；80 个 LIBERO-Pro Goal / Object / Spatial / Long 任务整体 99%。Jim Fan 的推文说，GPT-6 Astra 上线当天实验室换了后端，一夜之间所有 benchmark 刷到约 99%；成本-能力的帕累托前沿上是 Sonnet 5.5，约 12 美元一个任务。真机部分是 YAM 工作站上的魔方、拧瓶盖倒水、药丸入瓶、叠杯，外加一段仿真→真机的长程收桌子 demo。不过 README 自己写明了，新增的三个真机 recipe「是从 demo 会话里蒸馏出来的，不是新的真机验证」，也没有给真机成功率。

**它改变了什么。** 一是怎么读扰动版仿真基准。LIBERO-Pro、LIBERO-Plus 这类在相机、光照、布局上加扰动的基准，过去常被当作「泛化有多难」的证据——端到端 VLA 在上面普遍从九十多掉到三十以下。ASPIRE 这条路完全不学传感运动权重（LLM 写程序 + SAM3 分割 + 失败自诊断），只换后端就把 80 个任务推到 99%。这说明这些扰动对「显式感知 + 程序化控制」几乎不构成难度，它们测到的主要是**端到端策略对视觉和布局扰动的脆弱性**，而不是任务本身有多难。合理的推论是：今后在这类基准上报 VLA 的扰动成绩，应当把一个 code-as-policy 基线放进同一张表当参照系，否则「扰动下 X%」没有上限可比。

二是自进化系统怎么评。「失败数据 → 回灌微调」是具身自进化的主流想象，产物落在权重里，换主干就得重来。ASPIRE 的产物是可读、可迁移、和后端解耦的代码技能，后端一升级，库原样受益。但它的 15% → 99% 几乎全部来自后端升级，而不是技能库本身的积累——所以评估这类系统时，「库带来的增益」和「后端模型升级带来的增益」必须分开报，否则飞轮转没转起来根本看不出来。

要保留的一点：这里没读 PDF 正文，不确定仿真里的程序是否拿到了物体位姿这类特权状态。如果拿了，第一条判断要打折扣。另外 README 明确警告它会执行模型生成的、带完整 import 权限的 Python，执行进程和看门狗都不是安全沙箱，真机使用有单独的操作授权流程。

## 2. RAVEL：210 个 MLLM 上，给视觉编码器选型的指标重新排了座次

[arXiv 2610.05413](https://arxiv.org/abs/2610.05413) · [代码](https://github.com/JuntaoTang/MLLM-VisionEncoder-Eval) · [机器之心解读](https://mp.weixin.qq.com/s?__biz=MzA3MzI4MjgzMw==&mid=2651063453&idx=3&sn=6a2fa8d5b0af63412b2da5c4e4c222be)

问题很实际：不把 MLLM 完整训一遍，怎么预判哪个视觉编码器配哪个 LLM 最好？作者训练并评测了 **210 个 MLLM**（多种编码器 × 三个 LLM，覆盖连续编码器和离散视觉分词器、不同分辨率与预训练方式），先给出两个负面观察：最优编码器**会随 LLM 变**，所以线性探测这类单模态指标选不准；而已有的跨模态指标（Alignment Probing、GW、MutualNN）只在小而同质的候选池里占优，候选池一变大、变杂，它们的预测相关性就掉到不如单模态指标。

RAVEL 是一个免训练的跨模态最近邻检索打分，只加了两处改动：带稳定项的 PCA 白化（压掉特征空间里的主导方向），以及 patch 级相似度。三个 LLM 上平均 Spearman 0.85，比需要训练的 Alignment Probing 高 36.1%，比 GW、MutualNN 高 93.5% 和 101.1%。210 个 MLLM 权重全部开源。

值得注意的是那 210 个权重本身：想研究「视觉塔选择怎样影响下游」的人，可以直接拿它们当起点，不必重训对齐。但它的下游指标是 VQA 类，和机器人动作成功率之间的相关性没有验证过，不能直接搬到 VLA 的视觉塔选型上。这篇 arXiv 10 月 4 日提交，在论文源的时间窗之外，是从公众号这一路进来的。

## 3. Humanity's Sixth Sense：答案不在像素里的视觉推理基准

[Scale Labs](https://labs.scale.com/papers/humanitys-sixth-sense) · [数据集](https://huggingface.co/datasets/ScaleAI/HSS) · [新智元报道](https://mp.weixin.qq.com/s?__biz=MzI3MTA0MTk1MA==&mid=2652735434&idx=3&sn=140353f5aa81e8e8595cea5b5264e4d8)

Scale AI 与 Elorian 的新基准，测人类「瞄一眼就知道」的直觉式视觉推理：522 道开放题（288 张图 + 234 段视频，共 17.6 小时），分时间因果、物理与空间逻辑（遮挡、放不放得下、够不够得着、换个视角看到什么）、社会理解、抽象规则四大类 11 个子域。最有意思的是筛题规则——**答案不能直接出现在像素里**：放大就能看见答案的、需要专业知识的、人类自己判断不一致的，一律淘汰。3466 道候选题三轮独立审核只留下 15.1%。评分由 LLM 裁判按细则逐条判，全部满足才算对；换三家厂商的裁判重评五个模型，排名一致。

结果：人类 93.1%，榜首 GPT-6-astra 53.6%，25 个模型的中位数 30.9%。

对具身方向的价值在两处：「物理与空间逻辑」子域恰好是机器人用的 VLM 需要、而通用榜单不单独测的能力；「答案不在像素里」这条规则也可以拿来审已有的 grounding / pointing 评测集——不少号称考空间推理的题，其实是披了推理外衣的 OCR 或检测题。这里只读到了公众号全文，没有回读 Scale 的论文。

## 4. 四个 Gemini 智能体靠写代码和一份共享笔记打通《我的世界》

[新智元报道](https://mp.weixin.qq.com/s?__biz=MzI3MTA0MTk1MA==&mid=2652735434&idx=2&sn=55dfa1099296f2cdfaffc3f7975a33bf) · Google DeepMind

四个 Gemini 4 Argon 底座的通用编码智能体，被丢进一个随机种子、从零开局的生存模式世界，27 小时 14 分钟击杀末影龙。没有预设分工，DeepMind 只给了游戏内聊天频道和一份**共享笔记**；控制方式不是看画面按键，而是通过 Mineflayer（一个 JS 库）现场写程序。全程写了 2783 个程序，发了 229 条聊天消息，死了 605 次（Boss 战里就有 69 次），每次都是自己诊断后重来。作为对照，9 月 Vals AI 让 GPT-6 Astra 单人跑了 141 小时，基地被苦力怕炸掉之后就放弃了末影龙，转去种了几个小时土豆。反作弊上，服务端命令被禁用，再加一个独立的 Observer 智能体和人工抽样审计。

和第 1 条放在一起看：两条都是「代码当作操纵世界的通用接口 + 失败后自诊断重试」，而且都把长程进度放进一个外部可读的工件里（技能库、共享笔记），而不是放进策略的上下文。对「长程任务里机器人记不住做到哪一步」这个问题，这是 LLM 智能体一侧的一个对照。但 Mineflayer 给的是寻路、挖掘这类高层原语，离连续控制回路还很远。这里只读到了公众号全文，论文（arXiv 10 月 15 日）没有回读，所以共享笔记里到底存了什么、在多大程度上撑起了长程进度，目前还不知道。
