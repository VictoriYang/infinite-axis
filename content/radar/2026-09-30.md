## 1. 训练无关的加速方法「反超基线」，多半是基准 bug 和设计缺陷

**Faster and Better? Benchmark Bugs and Design Limitations Distort the Evaluation of VLA Acceleration** · [arXiv](https://arxiv.org/abs/2609.37771)

上海交大。起点是一个反常现象：DP-Cache、ProbeFlow 这类训练无关、只是**近似原策略计算**的加速方法，在仿真基准上的成功率反而高过被近似的基线。成功率这一个数说明不了收益来自执行更好还是评测有漏洞，作者把物体轨迹和末端轨迹画在 checker 的接受区域上定位根因（录全部 rollout 在 RoboTwin 上要多 85% 开销，所以只画轨迹），把 LIBERO、LIBERO-PRO、LIBERO-Plus、RoboTwin、RoboCasa、VLABench、RoboDojo 七个基准审了一遍：**22 个 bug 加 4 个设计缺陷**。

bug 分三类。任务一致性：LIBERO 的 Place Shoe 要求鞋尖朝向而指令没提；RoboTwin 的 Handover Block 指令漏掉 handover 这一步；VLABench 的 Select Painting 示教在按按钮。初始化：LIBERO-PRO 的 Turn On The Stove 指令说开、checker 要求关；LIBERO-PRO 场景与状态目录对不上，物体从半空掉下来；RoboCasa 的源台面和目标台面是同一个。可复现性：**RoboTwin 同一个 seed 会得到不同指令，因为 seed 不控制指令采样；杂物位置依赖同一进程里已经跑过多少 episode**；VLABench 的 seed 没传给场景生成器；LIBERO 没锁 MuJoCo 版本。设计缺陷四项：宽松 checker（Put Bottles Dustbin 把瓶子撞进去也算成功）、阈值敏感、物体质量不真实、动作平滑把加速度抖动藏掉——对最后一点他们加了一个偏好平滑动作的 motion-aware 分数。

结果直接翻转排名：修 bug 后 LIBERO-PRO 上基线 +52.8 个百分点、从末位变第一；RoboTwin 修正物体质量后基线从落后加速方法 21 点变成领先 5 点。附录给了四条指南：指令、示教、checker 三者对齐；验证真正送到策略手里的指令和实际初始化的场景；用「匹配的任务实例」比较，共享 seed 不等于相同任务；报告抖动、完成时间和超时。修复已开源。

这篇改变的是对「固定 seed」的信任。此前在 RoboTwin 上固定 seed 就默认两个方法跑的是同一批任务实例，成功率差异可以直接归因于方法；这组审计之后，「seed 相同」和「任务相同」要拆开看——需要显式记录每个 episode 实际拿到的指令和杂物布局做匹配实例比较。另外任何「训练无关加速反而涨分」的结果，先默认是基准问题而不是方法收益。

## 2. 推理时记忆的 fast weights 该挂在 VLM 侧，而不是 action expert 里

**T²Mem: Learning Test-Time Memory for Robotics** · [arXiv](https://arxiv.org/abs/2609.36720)

Stanford（Yize Liu、Huang Huang、Yining Hong、李飞飞、吴佳俊）与 NVIDIA。在 π0.5 上做 test-time training：用在线自监督更新把观测历史压进一组紧凑的 fast weights，避免重复处理整段历史，不依赖外部推理模型或记忆标注。关键设计是**记忆接口挂在 VLM backbone 和 action expert 之间的观测接地位置**——从 VLM 的视觉语言表示里提取信息形成记忆，把检索到的上下文送给 action expert；动作监督决定记忆该保留什么；记忆与策略交替训练，让每一方在优化时有一个固定的对手；写入规则是自适应的。16 个 RoboMME 任务平均成功率 17.93% → 56.83%，多数任务进前三，VideoRepick / InsertPeg / RouteStick 最好；弱项是两个 swap 任务，作者归因为 π0.5 本身缺跨帧时序推理。

最重要的是一组消融。把记忆放进 action expert、从动作表示读写（也就是 RoboTTT 那种集成方式），VideoUnmask / MoveCube 只有 30% / 26%；接在 VLM 侧的 T²Mem 是 84% / 71%。其他消融同样说明问题：不交替的联合训练约等于无记忆基线；关掉在线写入 VideoUnmask 掉 82.67 点；反事实记忆测试里正确记忆 300/300、冲突记忆 1/300、空记忆 101/300；同样写入预算下遮挡前写入 76.67%、遮挡后 20.67%。RTX A5000 上比 FrameSamp+Modul 和 MemER 快至少 3 倍。训练 32×H200 跑 48 小时，预测 64 步执行 32 步。没有真机结果。

这篇改变的是对 RoboTTT 路线的延伸方向。此前的默认假设是 TTT 的 fast weights 放在 action expert 里就够了，记忆学的是动作历史；这组消融之后，记忆容器该接到 VLM 侧的观测表示上、由动作监督决定保留什么——对需要记忆的任务，**记忆挂在哪一层比记忆机制本身更重要**，复现时先按这个接口位置搭，再比较记忆形式。

## 3. 示教预算固定时，集中在「舒适区」比铺满工作空间更好

**ComManip: Overfitting Manipulation Policies to Comfortable Regions** · [arXiv](https://arxiv.org/abs/2609.36928)

华南理工。一个反常识的发现：**固定示教预算下，把示教集中在一个视觉与运动学都稳定的「舒适区」，比把物体位置铺满工作空间的多样化采集更好**——Object Basket 上 15 条局部示教约等于多样化采集 5 倍数据的效果。原因是预算有限时多样化采集迫使策略去建模五花八门的观测，在相似局部条件下学不到可靠的观测—动作对应。部署时用 GroundingDINO + SAM2 找目标中心，移动底盘沿桌边逐步移动，直到目标中心进入示教时熟悉的图像空间范围，再跑同一个策略。

RoboTwin 2.0 六个任务（Stamp Seal、Empty Cup、Object Basket、Phone Stand、Hanging Mug、Stack Blocks），5 seed × 100 episode，ACT / π0.5 / RDT / OpenVLA-OFT / SmolVLA 都涨 20 点左右，ACT 上 71.6% vs 12.7%。真机 XLeRobot：Bottle Placing 10.0% → 73.3%，Blocks Stacking 6.7% → 56.7%（30 次）。舒适区过度扩大会掉分，Hanging Mug 在中等扩展下最好——适度的局部变化有帮助，但不是越多越好。

这篇改变的是采集策略。此前的默认做法是让物体位置、视角尽量覆盖整个工作空间，泛化靠数据多样性；这组结果之后，预算有限的采集该先定一个舒适区集中采，把位置泛化交给部署时的对齐（移动底盘或相机），只在舒适区内做适度扰动。

## 4. 异步执行会让动作分布塌缩，LIBERO 上看不出来

**Reactive Real-Time Flow Policies via Asynchronous Distribution Alignment** · [arXiv](https://arxiv.org/abs/2609.36540)

普渡与牛津机器人研究所。问的问题是：异步执行（边执行上一块边预测下一块）产生的动作分布和原 VLA 一样吗？答案是**对非马尔可夫示教不一样**——RTC、TT-RTC 这类 continuation-learning 目标在交接点得到的分布比同步 VLA 更窄，反应性受限。两个修补：Recursive Flow-Field Distillation 在已承诺的前缀之后用 VLA 的 flow 训练异步策略，理论上刻画了学到的分布，实验上能覆盖原 VLA 几乎全部的动作范围，而现有异步方法只能恢复一小部分；Propose–Resolve 异步准备多个候选序列，用最新观测在 VLA 分布的对角高斯近似下按似然选一个。

SmolVLA 上 LIBERO 与原 VLA 持平，RoboMimic（ToolHang、Square、Transport）保留约 80%，比异步基线高约 30 点。有意思的是分布对齐的价值是任务相关的——RoboMimic 上明显，LIBERO 上各种 proposer 差不多。局限：resolver 仍要跑冻结 VLA 的特征提取；对角高斯抓不到多峰分布。对做异步推理的人，结论是「和同步版本成功率持平」不够，还要看动作分布有没有塌缩，而且得在非马尔可夫示教上验。

## 5. 未来预测的监督从哪个接口进来，决定它能不能改善策略表示

**Where Predictive Supervision Goes Shapes What VLA Policies Learn** · [arXiv](https://arxiv.org/abs/2609.36645)

首尔大学。质疑「预测未来就能学到对控制有用的表示」这个前提：预测质量好不等于策略表示好，而这个区别在分布偏移下才显出来。在目标构造、预测地平线、训练条件都匹配的受控比较下，**不同的预测接口**——π 系模型原生的特殊 token 接口，还是直接在视觉 token 上预测——得到明显不同的预测和视觉表示，空间、动力学、动作信息向陌生场景迁移的程度也不同；差异追溯到预测误差如何流回策略的视觉流。更直接、与场景匹配的未来监督送到视觉流上，策略在仿真和真机分布偏移下更鲁棒，SmolVLA 上复现了同样趋势。要给 VLA 加未来预测辅助目标的人，先决定监督从哪个接口进来——它决定梯度到不到视觉表示，而不只是多一个 loss。

## 6. reset 时的扰动测不到「任务中途世界变了」

**LIBERO-MAX: Do Robot Policies Adapt When the World Changes?** · [arXiv](https://arxiv.org/abs/2609.36518)

现有鲁棒性基准都是在 reset 时固定外部条件，测不到目标中途移动、视角中途变化、障碍物中途出现这类情况。LIBERO-MAX 做了 8,000 对配对样本、八类中途事件（几何、观测、外观、杂物、路径），每对固定任务、初始状态、策略 seed 和事件前的动作序列，只差有没有事件——把事件导致的退化和本来就会失败的样本分开。14 个 VLA / 混合 / 世界-动作策略上事件造成 11.0–25.7 点下降；几何和观测变化是共同弱点，策略家族的排名互相交错；相机控制实验显示鲁棒性既取决于变化后条件下的能力，也取决于进入该条件的轨迹；调整查询频率不能消除差距。

这篇改变的是鲁棒性评测的边界。此前默认 LIBERO-Plus 这类 reset 时扰动已经覆盖了鲁棒性，加更多扰动类型就够；这组结果之后，「中途变化 + 配对对照」该当成独立的一项，评测协议里先分清退化是事件造成的还是本来就会失败，再谈鲁棒性。和第 1 条一起看，评测侧本期有两个具体动作：审自己在用的基准 checker，以及在 LIBERO 上加一组中途事件的配对协议。

## 7. 只看动作历史的记忆插件，在感知混叠型任务上也有效

**Remember What You Did: Action-History Memory with Dual-Expert Denoising for Long-Horizon VLA Policies** · [arXiv](https://arxiv.org/abs/2609.37307)

问题是感知混叠：长程任务里不同阶段的当前观测和状态相似，动作产生歧义。ActMem-VLA 的方案是**冻结微调好的 π0.5，只加一个记忆插件**：Mamba 编码已执行的动作历史，一个轻量的 PreAction Expert 在早期高噪声去噪步里按历史推进任务进程，再把部分去噪的动作交给冻结的 action expert 在低噪声步精修。只训 Mamba 和 PreAction Expert，额外参数 3.45%。LIBERO-Mem 十个任务平均 80.8%（π0.5 65.2%、MemoryVLA 49.5%），四个真机任务比 π0.5 平均高 28.8%。

和第 2 条正好是对照：T²Mem 说记忆要挂在 VLM 侧的观测表示上，这篇的记忆只用动作历史、挂在去噪的前半段，在感知混叠型任务上也有效。两篇合起来看，「记忆挂哪」可能取决于任务需要记住的是「世界发生了什么」还是「我做到哪一步了」——设计长程任务的记忆之前先分清是哪种。

## 8. 按「什么时候真的需要」分配去噪计算

**Urgent Actions Go First: Urgency-Aware Denoising for Real-Time VLA Control** · [arXiv](https://arxiv.org/abs/2609.37772)

观察是动作块联合生成、顺序消费，块内每个动作的紧迫度天然不同，现有加速方法却把整块当成一个计算单元。UAD 把去噪计算按需要的时间分配：紧急动作少去噪几步就放出去执行，尾部动作的继续精修和物理执行重叠。两个附带问题——早放出的动作有误差、尾部动作轨迹不一致——分别用 Trajectory Reconciliation（重建统一的内部状态演化恢复联合去噪一致性，不多跑模型）和 Ghost Action Correction（用未执行的 ghost 延续动态补偿剩余可执行动作的早放误差）处理。多个 VLA 架构、仿真基准和真机任务上，平均动作可用延迟最多 1.89 倍加速，成功率与最优去噪预算的原始推理相当。它和 KV cache 复用、少步采样正交，可以叠加——不过按第 1 条的结论，这类结果要配抖动和完成时间一起看。

## 9. 把大动作块切成错开去噪阶段的子块，用未来预测更新未执行的部分

**Staircase Policy: Streaming Inference for World-Action Models with Large Action Chunks** · [arXiv](https://arxiv.org/abs/2609.36471)

把 flow-matching VLA 改成 JEPA 式的世界-动作模型，把大动作块切成错开去噪阶段的子块：近端子块一可用就执行，远端继续精修；每个子块边界从最新观测重新预测未来 latent，用它更新所有未执行的动作，不重复跑完整策略——这同时解决了「后段动作条件于旧观测」的问题。未来预测误差还可以当自适应分块的信号。LIBERO 97.7%、LIBERO-Plus 87.9%；292.7 动作/秒，是常规执行 3.62 倍吞吐，首动作时间 123.6 → 73.3 ms，加推理优化后 642.9 动作/秒。和第 8 条思路相近，可以放在同一个延迟对比表里。

## 10. 视觉 token 剪枝的判据该是空间覆盖，不是语义重要性

**Beyond Token Importance: Preserving Spatial Scaffolds for Efficient VLA Inference** · [arXiv](https://arxiv.org/abs/2609.36967)

先做了一个简单基线：沿展平的一维视觉序列均匀采样 token（Stride），纯几何、不看语义——**在某些剪枝比例下反而优于语义剪枝和随机剪枝**，但预算稍降就崩。用「空间覆盖半径」（剪枝后保留 token 造成的最大空间盲区）解释这个现象：保留 token 的空间结构和任务成功强相关，VLA 剪枝要保留场景的空间骨架，不只是任务相关的 token。GeoScaffold 训练无关：把图像分区，用任务相关性分配区间预算，区内用最远点采样选骨架 token 压低局部覆盖半径。π0.5 + LIBERO 只留 20% 视觉 token 保持 93.2% 平均成功率，prefill 1.78 倍加速。要做 token 剪枝的人，Stride 基线本身值得在对比里保留。

## 11. 不执行、不采新示教，让世界-动作模型从自己生成的轨迹里学新任务

**EVO-WAM: Evolving World Action Models through Video-Action Verification** · [arXiv](https://arxiv.org/abs/2609.38057)

不采新示教、**不在外部环境执行候选动作**，让世界-动作模型从自己生成的视频-动作轨迹里学新任务。三步：给 WAM 训练加状态预测和锚定的多帧上下文，让它能不靠外部反馈做完整的自回归 rollout；用 VLM 选出完成任务的前缀、用逆动力学模型验证视频与动作一致，筛出可靠经验；在验证过的前缀上迭代训练、再生成。RoboTwin 2.0 七个未见任务：Cosmos3 26.9% → 68.0%，DreamZero 28.5% → 46.4%；真机三个未见长程组合任务 Cosmos3 20.0% → 76.7%。它的「自进化」不需要环境交互，和从失败出发的路线（前一期的 F4R / FailPatch）互补且更便宜，但摘要没说迭代几轮饱和。

## 12. 用 RL 训出来的闭环技能做树搜索，自动生成 39K 条示教

**SkillWeaver: Agentic Exploration over Neural Interaction Skills for Scalable Robot Data Generation** · [arXiv](https://arxiv.org/abs/2609.36171)

CMU（Fragkiadaki 组）。仿真数据生成不用开环控制器或脚本技能序列，而是把 RL 学出来的闭环、接触密集的操作技能做成可参数化的 Neural Interaction Skills，交给 VLM agent 做 verifier 引导的树搜索：决定下一步、调用并参数化技能、观察结果、生成验证 / 反思 / 记忆指导后续探索。自动扩到 14.1K 场景 39.1K 条示教，蒸馏成视觉运动策略后对新物体、新布局、新任务、新环境的泛化明显提升，支持零 / 少样本 sim-to-sim 和 sim-to-real。它的技能层是 RL 训的闭环策略而不是运动规划，接触密集任务能覆盖，和 RoboTwin 的脚本式生成对比时是另一端的参照。

## 未入选但值得一提

- **RoboActualizer**（[arXiv](https://arxiv.org/abs/2609.36413)，Tomizuka 组）：冻结视频世界模型编码器，只训一个 60M 的 actualizer 联合预测未来 latent 和动作，单卡 32GB 可训、延迟 39 ms，LIBERO / LIBERO-Plus / RoboTwin 2.0 都有结果。摘要没给具体数字，「和 VLA 相比」的结论无法核。
- **RoboFoundry**（[HF](https://huggingface.co/papers/2609.32862)）：把 agent 的上下文系统和技能系统当成可进化的策略，EmbodiedBench SOTA、RoboMemArena 领先 39%。进化的是 LLM agent 的系统层，不是 VLA 权重。
- **DEWO**（[arXiv](https://arxiv.org/abs/2609.37398)）：部署后学习里用成功 / 失败的视觉延续精炼世界表示做 classifier-free guidance，两轮部署学习真机 51.0% → 71.7%。灵巧手方向。
- **CrossBFM**（[arXiv](https://arxiv.org/abs/2609.38087)，Jan Peters 组）：把人形行为基础模型的 latent 空间当成跨本体可迁移资产，未见本体恢复 89% 跟踪性能。跨本体对齐的正面结果，但是全身控制不是操作。
- **CoRe-VLA**（[arXiv](https://arxiv.org/abs/2609.37150)）：外部相机偏移时 VLA 过度依赖腕部视角、子任务顺序出错；重建点云渲染回训练视角，不用额外数据不微调，真机 1.6m 偏移下 π0.5 13.3% → 83.3%。失效模式描述得好，方案是渲染绕过。
