## 1. 记忆方案的真正敌人是无关经历的累积，而一道检索就能完全抵消它

**RoboMME-Interference: Benchmarking Robot Memory Under Interference** · [arXiv](https://arxiv.org/abs/2606.22338) · [项目页](https://robotmemorybench.com)

这是一个跨 session 的基准，建在下面第 2 条的 RoboMME 之上。构造方式很干净：对每一个查询 episode，先放该查询真正相关的那条历史演示，再**可控地追加若干条互不相关的 session**，整段作为记忆喂给策略，然后量准确率。它做的事情是把此前一直被混在一起的两根轴拆开——**记忆容量**和**记忆抗干扰**。

拿 RoboMME 已经发布的那批记忆增强策略变体**原封不动**跑，结论分成清楚的三段。一，感知型记忆变体在**没有干扰项**、只给相关历史时确实提升成功率。二，随着无关 session 累积，这个提升**强烈且持续地衰减**。三，另一类变体（用一个视觉语言模型读历史、把写成文字的子目标交给策略）峰值收益更低，但在干扰累积下**保住的比例更高**。

最后一步是解法：给最强的那个感知型变体前面加一道检索——只挑出与机器人当前视野**视觉上最相似**的那段历史交给策略——结果是**在每一个干扰强度下都把无干扰时的成功率恢复了回来**。

**它改变了什么。** 长程记忆的工程叙事此前基本是「怎么把更长的历史塞进去」，检索式外挂被默认为上下文塞不下时退而求其次的方案，是一种为省算力付出精度代价的妥协。前一日那篇证明分钟级视觉历史只占几千 token、而主干支持数十万上下文的工作，还进一步强化了这个印象。这篇立起了另一根轴：**即使容量完全够、历史全都塞得进去，无关经历本身就是毒性输入**——成功率随无关 session 数量单调衰减，跟塞不塞得下毫无关系。所以检索不是容量不足时的妥协，**它本身就是抗干扰机制**，而且是能把损失完全补平的那一类。

由此有两条可操作的推论。其一，评测任何记忆方案都必须报出「追加 N 条无关 session 之后」的曲线；只报单 episode 内的成功率，等于根本没测抗干扰。其二，即便选择了原生长上下文路线，也仍应在前面挂一道按当前观测做的相似度筛选——这两件事不是二选一。

## 2. 记忆表示的有效性高度依赖任务类型，不存在一个通用最优解

**RoboMME: Benchmarking and Understanding Memory for Robotic Generalist Policies** · [arXiv](https://arxiv.org/abs/2603.04639) · [项目页](https://robomme.github.io)

密歇根大学与斯坦福等机构的工作，作者包括 Chelsea Finn、Nima Fazeli、Joyce Chai。它是本期另外几条的共同底座，处理的是一个元问题：视觉-语言-动作模型已经开始加记忆机制了，但**各家的评测都在各自狭窄、非标准化的设定里**，于是无法比较、无法度量进展。

两个产出。一是 **16 项操作任务**，按一套刻意设计的分类法组织，分别考察**时间、空间、物体、过程**四类记忆——对应「数一数重复了几次」「东西刚才在哪」「那个被短暂遮住的物体」「做到第几步了」。二是在同一个主干上做了 **14 个记忆增强变体**，横跨不同的记忆表示与不同的接入策略，系统地铺开对照。

核心结论只有一句，但很硬：**记忆表示的有效性高度依赖任务类型**。14 个变体各有胜负，每种设计在不同任务上都同时表现出明确的长处和明确的短板，没有一个通吃。

**它改变了什么。** 记忆这件事此前容易被当成一次性的架构决策——先挑一个方案，再铺开做。这篇说不行：**记忆表示和任务所需的记忆类型是耦合的**，选型必须先把任务按四类记忆拆开，再分类做消融。这一点与下面第 6 条合起来看更完整：既然不同表示擅长不同任务，那么只报一个总体平均成功率，就会把分类型的差异整个抹平。

另外值得单独提的是它的对照设计本身——把一批各说各话的方法拉到同一主干、同一评测协议下横向铺开——这类标准化工作在关键词密度上永远垫底，却恰恰是最能改变后续研究做法的那一类。

## 3. 把关键帧的筛选从「检索时」提前到「写入时」

**EventVLA: Event-Driven Visual Evidence Memory for Long-Horizon Vision-Language-Action Policies** · [arXiv](https://arxiv.org/abs/2606.20092)

中科大、上海人工智能实验室与华为等机构的工作。它对已有记忆方案的三分法值得先记下来，因为分得很准：要么**信息瓶颈严重**（压缩得太狠），要么**双系统解耦带来高延迟**，要么**无筛选的缓冲区堆积大量视觉冗余**。

做法叫「稀疏视觉证据记忆」，两个部件：一组基础视觉锚点负责保住初始与短时上下文；一个动态的**关键帧证据记忆模块**负责长时。后者的关键在于，它**直接从策略自己的隐空间表征预测未来关键帧的概率**——不是事后去历史库里检索，而是在当前这一帧还看得见的时候，就评估「它对未来的因果效用有多大」，据此决定要不要存下来。论文把这个机制称为前瞻驱动，目的是**在瞬时视觉证据变得不可观测之前把它留住**。配套还放出了一个诊断基准，专门评测非马尔可夫、带可交互视觉证据的任务。在 17 项需要记忆的仿真任务和 4 项真机双臂任务上，平均成功率比此前最强的记忆增强策略**高 40%**。

**它改变了什么。** 关键帧选择此前被普遍当作检索问题——先都存下来，用的时候再按相关性找回来，所以功夫该下在检索器上。这篇点破了一个隐含前提：**有些证据过了那一刻就永远不可观测了**——盖子盖回去、物体被挡住、提示消失。对这类证据，事后检索**无从检索起**，因为它压根不在库里。所以筛选的时机必须前移到写入时，而在写入时判断「这一帧以后有没有用」，只能靠预测。

这和前一日那篇批评压缩式记忆的工作正好是一枚硬币的两面：那篇说**写入时做不了正确的取舍，所以别压缩**；这篇说**有些取舍不在写入时做，就再也没机会做**。两者并不矛盾，真正的分界线是上下文预算够不够——预算充裕就全存，预算不够、或者证据本身会消失，就必须上预测式的写入门控。

## 4. 记忆写错方向会主动有害：把「尝试过」当成「完成了」，会把局部错误固化成持久状态错误

**AGM: Achievement-Grounded Memory for Closed-Loop Agents with Frozen VLA Policies** · [arXiv](https://arxiv.org/abs/2608.29537)

出发点是冻结策略的一个具体毛病：它提供了很宽的操作技能，但**开环地执行动作块、不跟踪任务进度**，于是系统无法可靠地决定该继续、该重试还是该终止。外挂记忆是自然的解法，而这篇指出了外挂记忆的反噬——**当被尝试过的动作被当作已完成的进度记下来时，一次局部执行错误就会被固化成持久的任务状态错误**。

方法是把任务表示成一个**子目标序列加一个进度指针**，而进度指针**只有在当前子目标被物理证据验证之后才前进**。两件事被明确分开：本体感知的交互线索决定**什么时候该去验证**；连贯点跟踪加上语言条件的跨视角比对决定**究竟完成了什么**。这两路都从冻结的基础模型里取，只额外训练一个 **243 万参数的验证头**。于是开环执行被转成「执行 → 验证 → 推进」的闭环，策略保持冻结，且测试时不需要跑大模型推理。在计数类子集上超过最强的记忆增强基线，真机上同样有效。

**它改变了什么。** 「有记忆总比没记忆好，最差也就是收益小」——这个默认排序是错的。这篇给出了一个明确的负向机制：记忆的**写入语义**搞错方向时，它会把瞬时错误变成永久错误。没有记忆时，一次抓空只是这一步失败；有了错误记忆之后，系统会认为「我已经放进去三个了」，后面全盘错。

所以记忆模块的第一设计点既不是容量也不是检索精度，而是**写入门控：凭什么认为这件事已经发生了**。而 243 万参数这个量级说明，一个独立的、基于物理证据的验证器其实很便宜，没有理由省掉。把这条和第 1、3 条放在一起，正好是同一件事的三个位置：**写入要门控，存下要筛选，取出要检索。**

## 5. 执行历史的贡献远大于参数规模

**PonderPounce: A Pretrained MLLM as an Episode Context Engine for Robot Control** · [arXiv](https://arxiv.org/abs/2608.24115)

立论是：多模态大模型本来就能整合长视觉历史、能从少量示例里推断行为，但视觉-语言-动作模型**很少把这份能力当成情景记忆来用**，反而去另造专用的记忆模块。所以这篇不造模块，**直接复用大模型原生的因果上下文**：一个预训练的慢思考模型吃 episode 历史和演示、持续产出「认知」；一个快速动作模型**异步地**以最新的认知**及其年龄**为条件产出控制。两者端到端联合训练，不需要单独的桥接预训练。

数字给得比较全。延迟方面，单次调用优化后，认知刷新的中位延迟 **78 毫秒**，动作模型调用 **25 毫秒**——这是双系统路线里少见的把实际墙钟时间摆出来的。效果方面，基准上基础数据规模 **60.83%**、九倍数据 **75.54%**，对照方法分别是 44.51% 和 57.88%；真机四项任务异步执行下平均 **60.98%**，对照 40.67%。

最值得记的是两组对照放在一起看：把慢思考模型从 **8 亿参数放大到 90 亿**（动作模型架构不变）只带来 **6.71 个百分点**的提升；而一个单独训练的 **90 亿参数模型在同等监督下去掉执行历史，只有 26.21%**。

**它改变了什么。** 双系统架构里，长程能力的上限此前被默认由慢思考侧的模型容量决定，于是「效果不够就换更大的规划模型」成了默认动作。这两组数字把账算反了：**同样是 90 亿参数，有没有执行历史的差距远大于从 8 亿放大到 90 亿的容量差距**。在把预算投给更大的主干之前，先确认历史上下文真的接进去了——前者的边际收益只有后者的零头。

另外那个「以认知的**年龄**为条件」的设计值得单独拎出来：异步双系统里，快速侧拿到的规划必然是过期的，**把「过期了多久」显式喂给动作头**，比假装它是新鲜的要诚实得多，而这个改动几乎零成本。

## 6. 把记忆的时间单元定在「子目标完成事件」上，并用分层切片证明增益没有被平均掉

**WeaveLA: Event Driven Cross-Subtask Latent Memory Weaving for Repetitive Robot Manipulation** · [arXiv](https://arxiv.org/abs/2606.17463)

问题陈述很精确：视觉-语言-动作模型在单步操作上已经相当好，**恰恰在「每一阶段依赖刚刚完成了什么」的地方脆**，而这是结构性的——短窗口模型没有跨子任务传递信息的显式通道。它对已有记忆变体的批评也是按写入时机来分的：要么**每帧都写**，要么**从演示时的阶段检索**，要么**在子目标事件上触发、但没有真正把信息交接进动作生成端**。

WeaveLA 认定**子目标完成事件**才是记忆交接的自然时间单元：在冻结的主干之上，把每个已完成的片段用查询驱动的注意力池化压成隐空间词元，**直接路由进下一个子任务的动作生成通路**，保留基础策略原有的短窗口接口，只加一条轻量的跨子任务通道。

而结果部分的**做法**比结果本身更值得学。在 RoboMME 上做**分层评测**：最难的重复切片上成功率从 **0% 涨到 47.8%**，而**单次执行的 episode 完全不变**；再用逐 episode 的配对分析确认，增益**严格局限在因果结构上确实需要跨子任务信息的任务里**。

**它改变了什么。** 这条改的主要是评测方法，不是模型设计。衡量一个记忆机制好不好，此前的默认做法是看它在长程任务集上的总体平均成功率。但这篇的增益形态是「一个切片从 0 到 47.8%，其余切片纹丝不动」——如果只报总表，这个增益会被不需要记忆的 episode 稀释成几个百分点，看起来像噪声，很可能被判为「没用」而放弃。

所以评测记忆机制必须做**分层切片加逐 episode 配对分析**，按任务的因果结构分组报告，而不是报一个平均数。这和第 2 条「有效性高度依赖任务类型」是同一件事的两面。它也提示了一个不太舒服的可能：**这个方向此前看起来进展慢，可能有一批本来有效的机制被平均数埋掉了。**

## 7. 长程任务的性能天花板不是演示不够多，是专家数据里根本没有「恢复」

**RaC: Robot Learning for Long-Horizon Tasks by Scaling Recovery and Correction** · [arXiv](https://arxiv.org/abs/2509.07953) · [项目页](https://rac-scaling-robot.github.io/)

卡内基梅隆大学的工作。现代模仿范式在大量人类演示上训练表达力很强的策略，但在接触密集、可形变物体、长程这三类任务上，**即使上千条专家演示，性能仍然停滞在远低于完美执行的水平**。这篇把归因给得很明确：不是架构不够强，而是**基于人类遥操作的「专家」数据采集流程本身低效**——专家轨迹里几乎不含分布外状态，也不含纠正，于是策略一旦漂出流形，就没见过该怎么回来。

方法是在模仿学习预训练之后加**一个新的训练阶段**，在人在回路的 rollout 上微调。介入协议是两段式的，这是关键：操作员在**失败即将发生时**介入，**先把机器人倒回一个熟悉的、分布内的状态**，**然后**给出一段完成当前子任务的纠正片段。在这种数据构成上训练，技能库被扩展出**重试与适应**行为。三项真机双臂任务（挂衬衫、密封保鲜盒盖、打包外卖盒）加一项仿真装配任务上，用**少 10 倍的采集时间和样本**超过此前的最佳方法。另有一条独立结论：**性能随策略表现出的恢复动作数量线性增长。**

**它改变了什么。** 长程任务停滞了就继续加专家演示——这个默认的扩容方向被判为错的，而且错在方向而非成本：**专家遥操作数据里结构性地不含恢复段，加到上千条也补不上这个缺口**，因为专家不会失败，也就不会演示怎么从失败里回来。

落到采集协议上，两段式里的**先倒回、再纠正**是不能省的一半：如果只补一段纠正而不先把机器人倒回分布内，数据里仍然没有「从分布外走回分布内」的那一段，而那一段才是真正缺的。落到预算分配上，10 倍的样本效率差距意味着——**同样的采集人力，投在恢复段上的边际收益比投在第 1001 条专家演示上高一个量级**。

最后那条「性能随恢复动作数量线性增长」还改了推理时扩展的图景：具身侧的测试时扩展不一定要靠采样多条动作再重排序，**让策略有能力多试几次本身就是一种扩展**，而这个能力是数据给的，不是搜索给的。

## 8. 把预测目标正交分解成多条通路，让弱但关键的信号不被强信号挤掉

**JEPA-Anything: Learning Predictive Models across Different Worlds** · [arXiv](https://arxiv.org/abs/2609.20800) · [代码](https://github.com/Gen-Verse/JEPA-Anything) · [中文报道](https://mp.weixin.qq.com/s?__biz=MzIzNjc1NzUzMw==&mid=2247924617&idx=1&sn=b62cd4d096d1ad94285a91a808f2fd6d)

本期**唯一一条从候选池里选出来的**。由 PhAI Labs 联合牛津、斯坦福、普林斯顿、香港中文大学与上海人工智能实验室完成。

问题设定：预测模型至今都是领域专用的，能不能有一个共同的学习原则支撑跨系统的世界建模。方法叫**正交预测分解**，是对联合嵌入预测架构的扩展——标准做法把信息全部汇入同一个目标嵌入、走同一条预测通路，而这里把隐空间的预测目标**分解成若干互补的因子，各走专用通路，最后在共享的预测设计里重组**。

动机说得很清楚，是一个**「预测容量如何分配」**的问题：当不同尺度、不同实体、不同难度的信号挤在一条通路上时，**更容易预测、变化更显著的信号会优先占据预测容量**，而微弱却关键的信息要么在梯度冲突里被抵消，要么被强信号掩盖。为防止多分支退化成「多套人马学同一件事」，方法加了正交约束，另有因子活性约束与编码器方差约束来防止失活和表示坍缩。这些因子**不被预先指定语义**，学什么由数据里的可预测结构决定，训练完还留下一个可供分析的内部接口。

七个领域验证：视觉、生物、临床轨迹、**控制**、分子动力学、物理场、天气。对照匹配的基线，10 项动力学任务**全部**改善；干预式 Pong 上单次干预的预测误差降 **34.8%**；四个分子系统上一步与百步误差都最低。另外两个结果是这篇被广泛转载的原因：模型自己提名的生物干预方案在细胞共培养、类器官、肿瘤组织块和小鼠上拿到了实验支持；隐空间的轨道模态还原出开普勒标度指数，拟合斜率 **-1.4991**（理论值 -1.5）。

**它改变了什么。** 异构数据集混合训练里的冲突，此前基本被当成一个**配比问题**——不同机器人、不同任务的数据打架，解法就是调采样权重、调损失权重，本质是在同一条通路上分配样本。这篇提供了另一根轴：冲突也可能来自**所有信号共享同一条预测通路**，于是「容易预测且幅度大」的信号（比如大幅度的末端平移）会系统性地挤掉「微弱但关键」的信号（比如接触时刻的细微调整）。这个失效模式跟配比没关系——调多少权重，都还是在同一条通路里抢。

需要诚实标注的是，把这一步外推到机器人策略训练是**迁移推测**：论文里的控制实验是干预式 Pong 这类玩具环境，不是真机操作。所以合理的结论是「值得做一组对照」，而不是「已经验证过」。

## 9. 抗遗忘要写进基座策略的目标函数，而不是在下游微调时打补丁

**Robust Policy Optimization to Prevent Catastrophic Forgetting** · [arXiv](https://arxiv.org/abs/2602.08813)

宾夕法尼亚大学与南加州大学的工作，纯语言侧，收它是因为方法结构可以直接迁移到机器人策略的后训练链路。

观察：大模型普遍走多阶段后训练——先做人类反馈强化学习，再为其他下游目标微调——而**即使很小的下游更新也会破坏先前学到的行为**（论文举的是安全性）。由此推出一件被普遍忽略的事：**标准的强化学习目标本身并不保证对未来适配的鲁棒性**。而此前绝大多数工作，都在设计**下游时刻**的方法去保住旧行为。

这篇的主张叫**微调前鲁棒性**：基座策略应当**避开那些脆弱的高奖励解**——也就是奖励在标准微调下会急剧下跌的解。实现上，是把奖励不只在当前策略上优化，而是在**下游适配可达的一个 KL 有界邻域内**一起优化，用极大极小形式保证策略漂移下的奖励稳定性。工程上它是改造 GRPO 得到的算法，**没有额外计算开销**。实验显示它在多个基座模型、多种下游微调范式下都显著降低了安全性退化，同时保住下游任务性能。

**它改变了什么。** 后训练的遗忘此前被当作**下游阶段的问题**，于是工具箱里装的全是下游时刻的东西——回放缓冲、KL 正则项、参数隔离、弹性权重固化。这篇把责任往前推了一整个阶段：如果基座落在一个「尖锐」的高奖励解上，下游再怎么小心也会掉，**问题在基座训练的目标函数里，不在下游的约束强度里**。

机器人策略的「大规模混合训练 → 特定本体或任务微调」这条链路，与语言侧的两阶段后训练是同构的。所以如果每次下游微调都要掉一截通用能力，正确的动作是回去改预训练阶段的目标，让它偏好在 KL 邻域内平坦的解，而不是在下游一直加正则。这一条与前一日那篇「遗忘多少由是不是 on-policy 决定」的工作补成一对：**一个说更新范式决定遗忘量级，一个说基座解的平坦程度决定遗忘量级**，两者都指向「别在下游打补丁」，但给出的是两个不同的前置开关。同样要标注的是，这篇**没有任何机器人实验**，上述是按结构同构做的迁移判断。
