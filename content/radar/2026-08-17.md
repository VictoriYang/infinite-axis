## 一、表征对齐：方向对，逐点拉齐不对

### 1. 4D-WAM：3D 轨迹监督只加在训练期

[量子位报道（团队投稿）](https://mp.weixin.qq.com/s?__biz=MzIzNjc1NzUzMw==&mid=2247912687&idx=3&sn=4d6cc22281b140edb3e62f54f2c15b8c)

世界动作模型（World Action Model）想把视频预测和动作生成统一在一个模型里：一边想象未来，一边输出动作。问题是这类模型大多仍在二维像素空间建模，而机器人看到的是 2D 投影、执行的却是发生在三维空间里、随时间演化的交互。书从哪里被抓起、沿什么方向移动、最终落到哪里——缺任何一环，视频预测都可以「看起来合理」，动作却不可靠。

自然的补法是拿一个 4D 基础模型的特征去对齐模型中间层。**这篇工作的前置实验说这条路不通，而且给出了原因。** 直接匹配绝对特征不仅没有稳定收益，反而造成优化冲突；进一步分析发现，典型视觉语言动作模型的视觉表征与 3D 特征确实正相关，但在基于 DiT 的世界动作模型里，中间表征与 4D 轨迹表征在多数层上接近不相关、甚至负相关。两者描述的是同一个世界，用的却是不同的「表征语言」——强行逐点一致，等于要求两张不同坐标系的地图拥有相同数值。

于是它换成对齐**动态规律**而不是静态数值，用 Trace Anything 提取的 3D 轨迹场作教师，加两项互补的辅助目标：

- **Motion Alignment**：把相邻两帧的表征分别做差，得到每个 token 的局部运动变化，再用 token 级余弦距离对齐两种表征的运动方向。模型不需要复制教师的绝对特征，只需要动得和真实轨迹一个趋势。
- **Destination Alignment**：把首帧当 source、末帧当 destination，计算 source-conditioned 的目标分布并最小化师生之间的 KL。只看相邻帧的模型容易擅长短时跟踪却忘掉整段操作要去哪，这一项把全局目标感知补回去。

工程上最值得注意的是它的形态：两项对齐是**只在训练期存在的辅助监督**，训练结束后教师模型、投影层、对齐目标全部移除，推理架构、参数量、延迟、显存都和原模型一致。

改变了什么：它把「引入几何先验」从架构问题降级成了 loss 问题——不改推理图就能做，这类改造的迁移成本比换 backbone 低一个量级。但更有转移价值的是那条负结果：**打算把几何或 3D 基础模型的特征蒸馏进策略模型时，应当先测一下自家各层与教师表征的相关性符号，而不是默认正相关就上逐点对齐。** 一个在 VLA 上成立的假设，换到 DiT 结构上就翻了号。需要说明的是，本次未能取得完整正文中的定量部分，「多任务多场景全面提升」是报道中的说法，也没有看到是否包含真机结果。

## 二、推理时计算：加深度不是免费旋钮

### 2. 循环模型为什么「越想越错」

[机器之心](https://mp.weixin.qq.com/s?__biz=MzA3MzI4MjgzMw==&mid=2651050586&idx=3&sn=b65c272d97e8e5262062ba3076fc6fb7)

标准 Transformer 像一栋楼层固定的大楼，无论问题是「1+1」还是一道复杂证明，生成每个 token 走过的深度基本相同。当前最成熟的补法是「一边说一边想」：多输出 token，就等于多调用同一套网络几次，简单问题少说、复杂问题多说。代价是中间计算必须被组织成一条可输出的序列，哪怕某些步骤根本没必要说出来。

另一条路是**在隐空间里循环**：回到某些层再走一遍，复用同一组参数，每转一圈更新一次隐状态。Universal Transformer、Deep Equilibrium Model 以及近年的循环 Transformer 都在问同一个问题——能不能让模型自己决定在「脑内」转几圈。

这篇综述的价值在于它把这条线的**失败证据**摆在一起（以下数字引自该文，未回原文核对）：

- 2025 年一项 latent reasoning 工作把循环深度模型扩到 35 亿参数、8000 亿 token，测试时增加循环轮数确实还能继续涨，单次前向最多能利用相当于 500 亿参数的计算量，不同任务在不同深度饱和。这是乐观的一面。
- 但循环语言模型 Ouro 早期用 8 轮循环训练就出现损失尖峰与梯度振荡，主训练阶段被迫降到 4 轮。测试时再把轮数加回 8，**额外计算没有换来更好的答案**：1.4B 的 Ouro-Thinking 在 AIME 2024 上第一轮 0 分、第四轮 65 分，第八轮掉回 38.67 分。多出来的轮数在帮倒忙。
- 2026 年的 Parcae 进一步指出循环语言模型容易出现残差爆炸与损失突然上升；重新设计循环过程中的稳定机制后，验证集困惑度最多降低 6.3%。

文章把待解问题归成三道坎：表达能力上够不够、模型能不能真正学会这种计算方式、以及训练结束后在推理期能不能稳定地继续算下去。第一道已有不少乐观结果，麻烦集中在后两道——反复调用带来误差累积，隐状态看起来稳定却支撑不住结果。

改变了什么：它给「测试时增加计算就能变强」这个正在被广泛引用的直觉划了一条边界。**外推到训练时没见过的循环深度，不是一个免费的推理期旋钮，而是一个需要训练分布显式覆盖的超参。** 对所有把持续更新或循环状态装进模型的工作（包括机器人策略上的对应做法），这条边界意味着评测必须专门报告「训练时未见过的更新步数下的表现」，只报训练配置下那一个点是不够的——那个点恰好是最好看的点。

## 三、多模态加速：删冗余，别删原型

### 3. CoverPrune：把 token 剪枝重写成覆盖问题

[我爱计算机视觉](https://mp.weixin.qq.com/s?__biz=MzIwMTE1NjQxMQ==&mid=2247664045&idx=1&sn=b1fa6c239a3db68daef008dc9d0c340e) · 报道给出的原文地址为 [arXiv 2608.13226](https://arxiv.org/abs/2608.13226)、代码 [Brucess/CoverPrune](https://github.com/Brucess/CoverPrune)（本次网络不可达，未能核对）

3D 视觉语言模型靠多视角几何观测换来空间推理能力，代价是几千个视觉 token 把注意力计算和 KV cache 一起撑爆。清华大学深圳国际研究生院与 LIGHTSPEED 的这项工作（报道称为 ECCV 2026 Oral）针对的就是这个瓶颈。

它先否掉了现有两条免训练剪枝路线在 3D 场景下的适用性：基于注意力权重的做法容易受 attention sink 和 prompt 显著性偏置干扰；而基于多样性选择的做法有**结构性缺陷**——在三维环境里，代表主干结构和核心物体的「原型 token」天然与多视角下的大量 token 高度相似，机械地按多样性去重，这些最核心的原型会被**优先当成冗余剔除**，保留下来的反而偏向背景离群点。多视角几何观测的一致性由此被破坏，空间距离测算、方位推断、物体排序这些任务大幅掉点。

它给出的替代判据是：从「最大化多样性」转向「最大化视觉证据的覆盖度」——保留集不该追求彼此各异，而应当作为一个紧凑的原型集合，尽量覆盖并解释全量 token 携带的特征、空间几何与时序信息。技术上写成一个最优传输问题，保留子集为源、原始 token 为目标，代价矩阵由三项构成：特征语义距离、经非线性变换放大近场敏感度的 3D 空间距离，以及一个**单向时序惩罚**——不允许后观察到的 token 去替代先出现的观察，以维持时空因果链。目标端容量不取均匀分布，而按每个 token 在 3D 局部邻域内的独特性得分分配，避免平坦冗余背景占掉传输质量。整体免训练、即插即用，挂在几何编码器与主干解码器之间。

报道给出的结果（引自中文报道，未与原文核对）：仅保留 10% 视觉 token 时，ScanQA 与 Scan2Cap 分别达到 100.00% 与 99.04% 的近乎无损表现，轻量版把剪枝本身的延迟压到 0.41 秒。

改变了什么：可迁移的不是这个模块，而是那条诊断。**凡是给多视角或点云输入的多模态模型做 token 压缩，用「特征多样性」当保留准则会系统性地删掉结构原型**；更麻烦的是这种退化在语言类指标上未必显形，只在空间关系任务上显形——属于典型的「指标涨了但能力没变强」的反面样本，应当写进评测清单而不是等上线后发现。另外那条单向时序惩罚，对任何吃多帧观测的模型都成立：允许晚出现的观测替代早出现的观测，等于悄悄破坏因果顺序。
