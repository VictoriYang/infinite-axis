## 1. GE-Act 2.0：世界-动作模型的预训练与扩展

[论文](https://arxiv.org/abs/2609.05588) · [HF](https://huggingface.co/papers/2609.05588)

世界-动作模型（world-action model）通过预测未来状态来指导动作，好处是既能吃无动作标签的视频、又能吃带动作标签的交互数据。此前这类工作大多**继承一个预训练好的视频生成器**，于是「世界-动作模型自己该怎么预训练、怎么扩展」这个问题一直没被正面回答。GE-Act 2.0 的选择是全部从零来：生成与动作两侧的可训练组件都直接在操作数据上初始化。

结构是三件：一个面向控制的自编码器（在激进压缩下保住与动作、指令相关的信息）、一个单步视觉规划器（一次可微前向就产出完整的未来状态，不做多步去噪）、一个逆动力学模型。视觉规划与逆动力学因此可以在互补的数据上分开预训练，再联合训练；联合阶段用了一个筛选机制，只把「与记录到的动作在行为上兼容」的预测未来拿去当监督，把错配的监督信号剔掉。评测直接使用预训练权重、不做逐任务微调，在 100 个任务 / 20 个技能组上跑，场景、背景、光照、物体实例全部留出。

真正值得记的是三个数字，它们改变的是**扩数据这件事该怎么规划**：

- 共训数据从 300 小时加到 30000 小时，两个本体上的成功率分别从 17.1% 涨到 44.1%、从 13.4% 涨到 31.1%。**百倍数据换来两倍多的成功率。**
- 其中一个本体的数据占共训总量不到 2%，成功率却涨了 17.7 个点 —— 作者据此判断存在跨本体迁移。
- 「技能组覆盖度」与零样本分布外成功率的相关性达到 Pearson r=0.80、Spearman ρ=0.85。

把这三条放在一起，异构数据混训的配比问题就换了个变量。业界常见做法是按数据量或按本体比例来配，而这里的证据指向技能覆盖：决定模型在没见过的场景里能不能成的，是训练集覆盖了哪些技能组，而不是某个机器人贡献了多少小时。少量的某本体数据更像是起对齐作用，不靠体量。同时那条百倍换两倍的曲线值得任何做数据规划的人抄进预算表 —— 靠继续加数据把成功率再抬一档，代价比直觉贵一个量级。

## 2. RoboSPA：把 benchmark 做成难度阶梯，而不是做得更宽

[论文](https://arxiv.org/abs/2609.05324) · [HF](https://huggingface.co/papers/2609.05324) · [代码](https://github.com/fanzhenxuan/RoboSPA)

现有的操作类数据集与 benchmark 大多在预设设置下考察任务完成度，对「模型在空间与流程复杂度上升时的推理表现」几乎没有分辨力。RoboSPA 冲的正是这两个维度：细粒度空间推理、长程流程规划。10 个任务类别 / 56 个基础任务，**每个任务被实例化成五档难度**（空间歧义与流程复杂度递增），共 280 个变体，527K 条轨迹，跨多个本体与多样场景。它也不止报二元成功率，另给了一组诊断指标。

结论是现有代表性 VLA 在三处仍然吃力：复杂空间关系、精确的低层执行、以及**记忆密集的规划**。

这里的方法论比结论更有价值。评测集变强通常被理解成加任务、加场景 —— 但那只是把评测变宽，结果是一个更平均的成功率，失败仍然无法归因。RoboSPA 的做法是把同一个任务沿难度轴展开，于是「在第几档开始掉」直接指向断在哪一环。做内部评测集时，难度分档的信息量高于任务扩容。

另外那个「记忆密集的规划」是这一期第二次出现的信号（另一次见第 6 条）：机器人基础模型普遍只吃当前观测，长程任务的失败常常不是策略不行，而是记不住做到哪一步了。

## 3. Environments as Scaffold：奖励太稀疏时，该改的是环境不是 agent

[论文](https://arxiv.org/abs/2609.08404) · [HF](https://huggingface.co/papers/2609.08404)

用强化学习把大模型训成能跑长程任务的 agent，最大的障碍是奖励稀疏。惯常解法是在 agent 一侧做冷启动（监督微调预热），但受数据量与探索范围的限制。这篇提出一个方向上的转向：**改环境**，构造「反馈更丰富的环境」。

关键不是「多给点反馈」这种废话，而是一条有方向的设计规则：在单回合探索的后期、以及跨回合演化的后期，反馈应当从「动作指导」退化为「观测增强」。换句话说，早期可以直接告诉 agent 该做什么，后期必须收回这种指导、只把世界描述得更清楚。在 SciWorld 与 BFCL 上跨多个模型规模、跨 GRPO / GSPO / DAPO 三种算法都有稳定增益。

分析部分有四条值得单独看：训练动态更稳（熵的波动下降）；难任务上出现了主动的状态空间探索；**环境给的指导被内化进了策略权重，而不是只在推理时当先验用**；组内反馈一致性是稳定优化的一条边界 —— 一致性破了优化就不稳。

第三条是这套做法能不能算「真的学会了」的判据。如果指导只在推理时起作用，那撤掉环境就退回原样，等于没训。这条也解释了为什么后期必须把动作指导撤掉：不撤，学到的就是「照着指导做」而不是策略本身。

## 4. CoVeR：多视角剪 token 该按空间覆盖，而不是按注意力重要性

[论文](https://arxiv.org/abs/2609.08345) · [HF](https://huggingface.co/papers/2609.08345)

把 3D 场景表示成多视角图像，可以让 2D 视觉语言模型复用预训练先验来做 3D 推理，绕开 3D 标注稀缺的问题，代价是视觉 token 数随视角数线性膨胀。已有的 token 剪枝分两族，这篇给两族各指了一处硬伤：

- **学出来的重要性打分**（按注意力或编码器特征排序）：多视角设定下的冗余**本质上是空间性的**，按重要性排会留下几个显著区域内彼此近乎重复的 token，大片场景没有任何代表。
- **体素化方法**：空间覆盖好一些，但无法强制一个精确的 token 预算，而且多视角在 3D 里互相重叠之后会饱和，保留率压不到目标值。

CoVeR 的做法反直觉地简单：**只用 token 坐标**，确定性地、免训练地选出一组覆盖场景全部区域的 token。它同时解掉了两族的毛病 —— 能精确控预算、突破体素化的饱和平台、也不会选出近重复。三个 3D 推理 benchmark 上全面超过此前 SOTA，作为即插即用模块在四个 VLM 上都成立；**约 8% 的视觉 token 保住了 93.5% 的全量性能**，平均比 SOTA 高 3.9 个点。

对任何跑多机位输入的系统，这条改变的是降本的第一步该做什么：先跑这个零训练的坐标覆盖基线，再考虑要不要训一个打分器。优化目标搞错了的话，训得再好也是在错的方向上用力。

## 5. TANGO：人形穿越杂乱空间，全身动作监督全靠仿真合成

[论文](https://arxiv.org/abs/2609.09158) · [HF](https://huggingface.co/papers/2609.09158)

传统方法把导航建模成 2D 路径规划，但人形机器人穿过杂乱的室内空间需要的是连续的、几何感知的全身适配：手臂怎么摆、躯干怎么调、步态怎么改，一起协调才能不碰到东西。TANGO 输入自然语言指令加第一人称 RGB，直接预测 29 自由度的关节空间动作交给下游全身控制器。

它的训练**全部在仿真里完成**，靠一条四段流水线合成出动力学上可行的监督信号：全局路径规划 → 运动学层面的全身动作生成 → 面向障碍的动作编辑 → 基于强化学习的跟踪。仿真评测上取得视觉语言导航的 SOTA，并在需要绕障的困难场景里超过强的模块化基线。最后零样本部署到 Unitree G1，在真实的杂乱场景里完成语言引导的穿行，**没有使用任何真机导航数据**。

值得记的是那条流水线的分工顺序：先规划出路径，再在运动学层面生成全身动作，再针对障碍编辑，最后用 RL 补上动力学可行性。这是一条不依赖遥操作就能造出全身监督的路径 —— 对「真机数据贵」这个约束是绕开，不是缓解。需要注意的是真机部分只给了「稳健穿行」这类定性描述，没有成功率数字，别当量化证据用。

## 6. Kalman Delta Networks：给循环记忆的每次写入加上置信度

[论文](https://arxiv.org/abs/2609.07816) · [HF](https://huggingface.co/papers/2609.07816)

线性注意力越来越多地被用在前沿语言模型里做高效长上下文推理与常量内存解码。但它那个固定大小的循环记忆有一个结构性难题：每个 token 都必须**在线**决定写什么、以多强的力度覆盖已有的关联，而这个决定必须在还不知道未来的查询需要什么的时候做出。Delta 规则类模型从当前 token 的嵌入里学这个覆盖强度，但**不跟踪对记忆估计本身的置信度**，于是每次写入无法根据已经积累的证据来调整力度。

这篇的做法是把循环关联记忆重新写成一个线性-高斯状态空间模型 —— 在这个形式下卡尔曼滤波正是最优的递归估计器。于是状态转移可以同时传播记忆和它的不确定性，卡尔曼增益按累积证据与观测可靠性给每次残差写入加权。一个漂亮的结果是：Delta 类更新在这个框架下成了一个特例，相当于用逐 token 的各向同性代理替掉了预测协方差、并省掉了协方差跟踪。

精确跟踪需要稠密的、状态相关的 Riccati 递归，对 GPU 上的并行扫描很不友好，所以文中给了两个可扫描的近似：对角 KDN 通过在线均场变分把每步后验投到对角高斯族；各向同性 KDN 每个 head 只留一个不确定性标量。两者的不确定性递推都是 Möbius 映射，因此能做对数并行深度的关联扫描。750M 与 1.3B 的受控预训练上，困惑度与下游平均准确率都稳定优于此前的 SOTA 线性注意力。

放到具身语境里，它的意义不在困惑度，而在于**它是一个不同的记忆容器**。此前把「部署后持续变强」做进机器人策略的代表性路线用的是快权重（TTT 层那一类），这篇给的是带不确定性的关联记忆，写入强度由累积证据决定而不是由当前观测决定。控制回路里那个「这一帧到底该不该改写我对任务进度的记忆」，恰好是同一个形状的问题。目前只有语言侧验证，具身侧还没有实验。

## 7. DriveZero：感知与动作要用两套配方，所以分开预训练

[论文](https://arxiv.org/abs/2609.06055) · [HF](https://huggingface.co/papers/2609.06055)

大多数端到端自动驾驶系统靠模仿人类驾驶日志来学，于是学到的行为上界被记录轨迹的质量与行为覆盖度锁死。DriveZero 的结构性主张是：**感知与动作需要的学习方式根本不同，因此应该各自在最适合的范式里预训练，再合并成一个端到端规划器。**

感知要理解世界，受益于海量多样的视觉数据 —— 它把 DINOv3、SigLIP2、SAM、Depth Anything V2 几个冻结的视觉基础模型只从原始图像整合进一个 backbone，不需要任何任务标注。动作要与世界交互，需要闭环反馈 —— 它把真实驾驶日志转成可交互的世界，在里面用 PPO 做闭环 rollout 训一个特权教师策略。最后把这个冻结的教师通过其 rollout 轨迹蒸馏成一个纯相机的规划器。

有个细节值得单独提：那个目标条件的教师**可以在被改写过的驾驶意图下被查询**，从而产出记录数据里根本不存在的、但目标一致的多样监督。这等于把「记录数据只覆盖了实际发生的那一种意图」从一条硬约束变成了一个可采样的维度。结果上，nuPlan 三个 community split 的均分 93.57，在非反应与反应两种模式下都超过 Log-Replay 专家；NAVSIM v1/v2 与闭环 HUGSIM 上取得 SOTA，且**不使用任何人类轨迹监督**。

这套思路能不能搬到机器人操作，卡在工具链上：自驾有相对成熟的「日志转可交互世界」的基础设施，操作侧目前没有对等的东西。

## 8. Procedural Graphs：把流程知识显式化，并且记住失败过的编辑

[论文](https://arxiv.org/abs/2609.09153) · [HF](https://huggingface.co/papers/2609.09153)

大模型作为 agent 长程规划、调用工具时，绝大多数实现是在不断累积的历史上做无约束生成来选下一个动作 ——「做什么、按什么顺序、在什么条件下」这层流程知识始终是隐式的。轨迹一长就出现三种典型退化：丢掉目标、乱序调用工具、反复重复无效动作。

这篇提出的类比很清楚：知识图谱把事实知识组织成（实体, 关系, 实体）三元组来回答「是什么」，流程图谱则把流程知识组织成（流程, 关系, 流程）三元组来回答「该做什么」。每个决策步先定位 agent 当前的活跃节点，再由一个 guidance 模型把周边子图翻译成步级的情境指导 —— 注意是**偏置**下一个动作，而不是指定它。

图本身是自演化的：一个 refiner 拿失败轨迹去对照成功轨迹，编辑图的拓扑与属性，只提交那些能保持或改善留出集性能的编辑，**同时把被拒绝的编辑保留下来，用于抑制重复尝试**。从一个最小骨架起步就能长出匹配甚至超过手工设计的图，也能修正一个本身有缺陷的专家先验。跨多个数据集、任务类型与底座模型，都稳定优于基于记忆的基线。

「保留被拒绝的编辑」这个细节比主结构更值得抄。凡是做技能自主入库的系统，通常只记录成功的技能，于是同一条死路会被反复重新发现、反复浪费预算。把失败过的修改也存下来，成本极低。全部实验在文本 agent 上，没有具身验证。

## 9. Puffin-World：把重力方向当成要显式传播的状态量

[原文（中文）](https://mp.weixin.qq.com/s?__biz=MzIwMTE1NjQxMQ==&mid=2247665036&idx=1&sn=8a7d9c2046de919927bb0ae1b91781ed)

出发点是一句值得反复讲的话：**看起来真实不等于理解世界。** 当相机大幅旋转、沿长轨迹运动，或者参考视角本身重力不对齐时，视频生成模型并不知道真实世界里「上」在哪 —— 表现是地平线缓慢漂移、物体朝向发生变化、不同视角看似连贯却并不共享同一个稳定的物理与几何坐标系。

Puffin-World 的做法是让一个模型同时学三种彼此关联的原生状态：**物理状态**（重力场加纬度图，描述场景的直立方向、地平线位置、每条观察射线相对水平面的俯仰）、**几何状态**（以深度为核心，表达画面背后的三维结构）、**外观状态**（RGB 与连续视觉序列）。核心表示叫 Omni-Camera，把两类相机表示拼成一套：绝对表示能表达重力与直立方向但难从单张图获得，相对表示擅长描述视角间的运动却缺少全局参照 —— 于是一部分描述每个像素对应的绝对物理方向，一部分描述射线起点与方向构成的相对几何。

还有一步是物理状态的传播：相机沿轨迹运动时，按已知的相对旋转把初始的重力方向传播到每个新视角，再为目标视角生成对应的重力场与纬度图。相对运动只告诉模型「相机怎么动了」，物理传播进一步告诉它「动完之后在真实世界里朝向哪」。于是长轨迹、极端旋转、复合运动下，整个生成序列仍然锚在同一套重力与地平线参照上。整套不依赖任何外部模型。

值得记住的是这个切法本身：把重力方向当成一个需要显式建模、并且需要沿轨迹传播的状态量，而不是指望模型从数据分布里隐式学会。需要说明的是这是项目方自己的技术介绍，只有定性描述与方法结构，文中**没有可核实的量化对比** —— 按方法参考读，不按结果读。

## 10. Reason Through the Latent：怎么证明隐表示真的被用上了

[论文](https://arxiv.org/abs/2609.06746) · [HF](https://huggingface.co/papers/2609.06746)

隐式视觉推理的目标是用隐状态计算替掉显式的文本思维链。这篇指出了这一整类工作里的一个方法论漏洞，而且它比论文的具体方法更重要：**视觉信息存在于某个隐状态里，不等于模型在产出答案时真的依赖了那个隐状态** —— 只要还有别的以图像为条件的通路可走，模型完全可能走别的路，而探针照样能从隐状态里解码出信息。

它的构造（CVRR）是把递归计算变成通向预测的**必经**的图像条件通路：从视觉语言模型已经吸收图像之后的问题隐状态开始递归，反复更新这个状态、每一轮重读同一份固定的视觉证据；在解码之前，把视觉状态与原始的多模态 KV cache 全部移除，于是只有最终的递归状态还携带着图像条件信息。在 V\*、MMVP、BLINK、MME-RealWorld-Lite 上，CVRR 在这个严格接口下仍保持强性能，而可比的隐式推理器即使在同样的约束下重训，也恢复不出可比的视觉能力。因果干预进一步显示：问题固定时预测对递归内容敏感，持续的视觉证据会因果地修正递归轨迹。

把这套协议单独拿出来，它是一个通用的验证工具：要证明某个中间表示真的在参与决策，靠的是**物理切断所有替代通路**，而不是看探针能不能解码出信息。任何声称模型内部有「隐式规划」「潜在思维链」的工作都该过一遍这道门。

## 关于本期的主动检索

除了按时间窗抓取，这个雷达每天还会带着一份固定的问题清单去检索（不限发布时间，只要它回答了问题就算命中）。今天轮到的三条问题分别关于：领域内可证伪的一手判断、把模型跑进真机的工程实测、以及「其实不需要某个组件」这类反直觉的负面结果。**三条全部零命中。**

失败模式是一致的，值得写下来：这些问题里的技术术语恰好和其它领域的高频词撞车。搜「ablation shows component unnecessary」被医学意义的消融（前列腺、心脏）淹没，中文搜「消融」全是概念科普；搜「control frequency ... success rate」返回的是治疗成功率、银行协商成功率这类只匹配了「成功率」的噪声，中文搜「时延」返回的是空间机器人的**网络传输**时延补偿控制，跟推理时延毫无关系；搜「量化」则撞上量化交易。第一条问题的两次检索都只回到 2023 年那篇机器人基础模型综述及其中文转载，复述的是已经共识化的「数据是瓶颈」，不构成新的可证伪判断。

结论不是这些问题问得不对，而是检索词的区分度不够 —— 抽象的方法论词汇在搜索引擎里几乎没有分辨力，得换成具体的载体名（具体硬件平台、具体模型名、具体组件名）。另外今天的网络本身处于降级状态，检索质量也受了影响，所以调整之后需要在正常的一轮里复测再下结论。

把零命中如实记下来，本身是有用的信号：它说明的是问题清单或检索方式该动了，而不是这一天没有值得读的东西。
