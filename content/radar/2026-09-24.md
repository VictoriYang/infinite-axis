**本期主线**是否定结论。两篇工作各自推翻了一个默认假设：一是「flow matching 微调时先验越接近目标越好」——TRI 在三个基座、四十多个任务、十万次以上仿真加 1250 次真机盲测上没找到差别，差别全在 encoder 学习率里；二是「记忆 benchmark 成功率高、扰动记忆后动作会变，说明记忆机制有效」——反事实审计发现策略可以对历史敏感却不用它选分支，真机上九次完成的归位有五次放错了目标。第三篇 X2Real 不算否定，但把「仿真-真机相关性 0.84」拆开之后，读者会发现摘要挑的是进度分口径，成功率口径含精细任务只有 0.74。三篇放在一起，共同点是**先怀疑指标在测什么**。

## 1. 微调 flow matching 策略时，高斯先验就够了

**The Gaussian Is Enough: Flow-Matching Priors Do Not Help When Fine-Tuning Large Behavior Models** · [arXiv](https://arxiv.org/abs/2609.27070) · [项目页](https://cxu-tri.github.io/non_gaussian_FT/)

TRI（Chen Xu、Masha Itkina、Haruki Nishimura，合作者 Hadas Kress-Gazit）。从头训练 diffusion / flow 策略时，把去噪起点从标准高斯换成更接近目标分布的先验，文献里有明确收益。这篇问的是这个收益能否迁移到微调大行为模型（LBM 1.0、π0.5、GR00T N1.5）上——直觉是应该更大，因为预训练策略本身就是一个现成的好先验。

实验规模是这篇的底气。七种先验：标准高斯；三种由预训练模型自身构造（半去噪的预训练动作、加噪的预训练动作、加噪的 embedding）；Cocos；BRIDGER 的 CVAE；k-NN 检索。仿真侧 LBM Eval 8 个任务 × 5 个数据比例，RoboCasa365 34 个任务 × 200 次 × 两个基座，合计超过十万次 rollout。真机侧五个双臂 FR3 任务（食物银行分装、清理厨台、备烘焙原料、收拾餐盘、装自行车转子），每个先验每个任务 50 次**盲测 A/B**，共 1250 次。结果：真机上五个先验里四个落在同一个统计分组，部分进度 71–77%；BRIDGER 更差，因为 CVAE 微调不稳定。唯一的例外在 5% 数据（每任务约 10–20 条示范）——加噪 embedding 先验略胜高斯。

诊断部分比结论更有价值。不同先验微调出来的 encoder embedding 彼此偏离很远，但用 LogME 度量的可迁移性和最终的动作预测几乎一致——微调过程把先验的差别吸收进了 encoder。学习率消融坐实了这一点：把 encoder 学习率调低，所有先验一起从仿真 56–59% 掉到 41–43%、真机 37% 掉到 28%，这一个旋钮的效应量完全盖过先验之间的差距。作者的建议直白：微调预算该花在 encoder 上，不该花在先验设计上；learned prior 只在每任务示范少于 20 条时值得再看。

## 2. 记忆改变了动作，不等于记忆在指导动作

**Memory That Changes Action Is Not Memory That Guides It: Counterfactual Auditing of History-Conditioned Robot Policies** · [arXiv](https://arxiv.org/abs/2609.27247)

HKUST-GZ 与上科大。带记忆的机器人策略通常用两种方式评：任务成功率，或者扰动记忆后动作有没有变。这篇指出两者都不能证明「记忆决定了正确的行为」。它提出 Counterfactual Memory Audit（CMA）：构造两段都合法、在当下观测上完全一致、但要求不同后续动作的历史；同一个冻结策略在共同随机数下分别以两段历史查询；每个动作各放进两个只有评估者知道的真实世界里评分。这把问题拆成四层——记忆是否敏感、是否选了对的分支、在匹配的世界里物理上值多少、逐对是否可靠。

审计对象是 Mem-0（RMBench）和 BridgeVLA++。「归位」任务上 64 对历史全部改变了动作，但只有 20 对可靠地选对了分支；后一个「交换」决策点上 24 对全部改变动作、却没有一对换到不同分支——记忆在起反应，不在做决定。原生干预进一步确认闭环影响是真实的：换掉 history bank，行为跟着新内容走；给 bank 注入故障后恢复一个 4096 字节的受保护锚点，能挽回 38.9 个百分点的交换成功率。双臂真机上，九次完成的归位有五次放到了错的目标。

这篇的意义在于它给「记忆做进控制回路」这条线一把新的尺子。此后再看记忆增强策略在 RMBench 一类基准上的成功率，应当把它当弱证据，去追问有没有做过反事实配对的审计。

## 3. 仿真-真机相关性 0.84：进度分口径，含精细任务的成功率是 0.74

**X2Real: an eXtensive simulation benchmark for real-world generalist policies** · [arXiv](https://arxiv.org/abs/2609.27449) · [GitHub](https://github.com/X-Square-Robot/x2real)

自变量机器人。基于 Isaac Lab-Arena，配一个叫 Mana 的仿真平台和一套物理领域专用语言，10 个能力维度、44 个层级化长程任务，硬件覆盖自家 ArtiXon Arm-6A、Quanta X1 以及 Franka、ARX R5，随附约 300 小时仿真轨迹（八成遥操作、其余自动合成）。用训练中没有任何仿真数据的 Wall-OSS-0.5 标定仿真与真机的相关性。

正文把这个数字按口径拆开了：通用任务上成功率相关 0.96、进度分相关 0.99；把三个精细任务算进去后成功率相关 0.74、进度分 0.84。摘要里的 0.84 是后者。精细任务在仿真里普遍失败，作者归因于仿真侧的高失败惩罚——也就是仿真对毫米级操作比真机更苛刻。这个拆解本身就是有用信息：任何一个基准报「相关性 0.8+」，都要问是哪种指标、有没有剔掉精细任务；这篇给了一个在精细任务上掉 0.2 的实测量级。此外它还做了自动合成轨迹与遥操作轨迹的对照（12 块堆叠，各 1398 条，π0.5 微调），以及训练 / 评测流水线严格分离的设计来防止基准被过拟合。

## 4. 非对称视频-动作模型：世界模型的预测不重生成，靠编辑缓存的 K/V

**InternW0: A Foundational Physical World Model for Efficient Real-World Interactions** · [arXiv](https://arxiv.org/abs/2609.27656) · [项目页](https://internrobotics.github.io/internw0)

上海 AI Lab。视频-动作混合 Transformer：大容量的 Video-DiT（冻结 Wan VAE + DINOv3）负责长视野预测，轻量的 Action-DiT 以更高频率跑 flow matching。关键设计沿自 AHA-WAM 的 chunk 级 K/V editor：动作更新时不重新生成未来，而是用零初始化的门控残差 ΔK/ΔV 把已缓存的 layerwise K/V 调到新观测上。关键路径 60.73 ms、16.47 Hz（RTX 5090D），比 Fast-WAM 快 3.13 倍。

数据 7200 小时，来自 AgibotWorld、Galaxea、RoboCOIN、MolmoAct、InternData-A1、RoboDojo 和自采的 275 小时实验室第一视角数据 EgoLab；动作接口统一到 37 维（每臂 7 关节 + 3 末端位移 + 6 维旋转 + 1 夹爪，加 3 维底盘），按各数据集规模平方根比例采样。RoboTwin 2.0-Full 上三个 seed 93.20 / 93.04 / 93.12，与 ABot-M0.5（94.10）、OpenWAM-α（93.60）同档；EgoLab 消融（约 50 小时机器人数据 + 50 小时第一视角）clean 72.13→76.40、randomized 13.73→21.97。真机是一条 15 阶段的金属有机框架合成流程和带力觉的定量移液。它是「世界模型的好处不付世界模型的延迟」这条路线的又一个实例，和第 11 条 LeWAM 形成对照。

## 5. 固定大小的情景记忆，替代不断增长的上下文

**MemBodied: Recurrent Associative Memory for Vision-Language-Action Models** · [arXiv](https://arxiv.org/abs/2609.28256)

SUTD（Soujanya Poria 组）与 NTU。绝大多数 VLA 只看当前观测；把历史观测塞进上下文能解历史依赖任务，但代价是上下文和延迟一起膨胀。MemBodied 用固定大小的记忆替代：一个 associative state 跨策略调用累积交互记录，一个 episode anchor 保留初始场景的紧凑表示作参照；每次调用以当前输入加这两块作条件生成动作。五个需要记忆的 RMBench 任务上，成功率是无状态策略的 7.81 倍、朴素循环记忆的 2.98 倍，比最强的记忆增强基线高 1.3 倍而新增参数少一个数量级；全可观测的 LIBERO-Long 上 90.6%，比无状态 π0 高 5.4 个点。摘要里没有第 2 条那种决策级审计——这正是读它时该带着的问题。

## 6. 把 advantage 引导的后训练拆成三个可分别检验的选择

**Dissecting Advantage-Guided Post-Training for Vision-Language-Action Policies** · [arXiv](https://arxiv.org/abs/2609.28161)

上交等。用 critic 的 advantage 给示范加权再训练 VLA，是少量真机数据下的实用后训练方式，但 advantage 怎么构造（MC 还是 TD）、怎么校准（分组还是全局）、怎么用（二值过滤还是连续加权）三个选择通常捆在一个配方里，看不出各自效应。这篇把它们拆开，并为每一阶段设计**离线**诊断来筛选候选，不必每种组合都跑真机。筛出的配方是 TD 构造 + 组内校准 + 连续加权；四个真机双臂任务上比 SFT 初始化平均进度 +0.42、成功率 +0.63，且离线诊断与真机结果方向一致——后一点对任何想省真机评测预算的人都有参考价值。

## 7. 人类纠正在哪些维度可信，本身是可以预测的量

**BEE: Intervention-Adaptive Real-World Reinforcement Learning with Vision-Language-Action Models** · [arXiv](https://arxiv.org/abs/2609.27450)

真机 RL 离不开人类纠正，但现有方法要么用不上纠正，要么把它当成无差别监督。BEE 的观察是人的纠正沿某些动作维度稳定、沿另一些维度飘忽。它训练一个 Correction Model 预测人会怎么改 VLA 的提议、以及沿每个维度的一致性；一致性高的维度把策略约束得紧，低的放松。VLA 本体冻结，在其上做 RL。三个真机任务加一个 LIBERO-Pro 任务、匹配在线数据预算下平均 91.2%，对比 RLT 57.5%、DSRL 42.1%，真机干预率也最低。arXiv 元数据没有作者单位。

## 8. 永不重置的机器人：把「自己做过什么」而不是观测存进记忆

**Watch, Recall, Act: Always-On Robots in Concurrent Embodied Streams** · [arXiv](https://arxiv.org/abs/2609.28429)

现有动作模型假设固定指令、无中途干预、单步推理。ARMS 针对相反的设定：指令中途到达和失效、场景在变、需要回忆自己远过去的动作、双臂并发。方案刻意简单——一个 π0.5 主干加三个轻量模块（实时感知、本体状态头、自身历史动作），异步更新上下文，所以「看」和「回忆」不阻塞「动」；agent-causal self-history 记录哪只手在何时做了什么。配套数据集靠分阶段构建脚本自动标注每个模块的监督信号。组合任务 45% 对最强基线 28%，消融说三个模块各自必要。和第 5 条放在一起看是记忆的两种切法：存观测的压缩，还是存自身动作的日志。

## 9. 人只在规划器不会的段落介入

**TANDEM: Task and Motion Planning with As-Needed Demonstrations for Efficient VLA Fine-tuning** · [arXiv](https://arxiv.org/abs/2609.28314)

Princeton（Tom Silver）。遥操作者花大量时间演示机器人已经能自主完成的部分。TANDEM 把人的协助建模成 TAMP 里的按需规划能力：VLM 给规划域补上缺失的谓词和由人执行的 magic operator，规划器自动在自主段和人工段之间穿插，每段人工之后重新感知、校验预期效果再继续，不需要任务特定的干预点。为了让数据能微调 VLA，还用预训练轨迹样例把规划器生成的动作对齐到目标模型的预训练分布——这一步容易被忽略。五个超出 TAMP 域的长程任务上，同样人工干预时间收集到 2.9 倍示范；每任务 20 条微调 π0.5-DROID，平均成功率从 0% 到 60%。

## 10. 让 coding agent 写策略，再把验证过的解法扩成训练数据

**EmbodiedSWE: Coding Agents for Long Horizon Dexterous Robotics** · [arXiv](https://arxiv.org/abs/2609.27308)

Princeton / Stanford 等。EmbodiedSWE-Bench 覆盖接触密集、可变形物体、最长半小时连续交互的任务。前沿 coding agent 能解并能跨任务、跨本体迁移已有解法，但需要大量迭代交互，且解法通常只对单个任务实例有效——这是这条路线的真实瓶颈。EmbodiedSWE-Gen 把单个解法扩成大量多样轨迹训练 VLA：示范越多性能越好，agent 辅助的多样化提升对留出变体的泛化；只用 agent 生成的仿真示范微调的 VLA 在真机完成了一个长程任务。它和程序化生成是平行的数据来源，共享同一个质量控制问题。

## 11. 不需要视频扩散主干的世界-动作模型

**Latent evolving World Action Model** · [arXiv](https://arxiv.org/abs/2609.27455)

百度等。世界-动作模型通常绑在预训练视频扩散模型上，性能和成本都由视频生成预训练决定。这篇比较了视觉表示对动作生成的影响，结论是 JEPA 类预测性 embedding 比 VAE 压缩 latent 更适合作动作生成的条件（I-JEPA 最好）；于是 LeWAM 直接在 JEPA 空间预测未来 embedding 来建模环境演化，不要视频扩散主干。另加 DemoDPO：从示范里直接导出偏好对做离线偏好精调，不需要额外交互或人工重置。0.4B 可训练参数在 RoboTwin 2.0 上 92.28%，与 SOTA VLA / WAM 同档。和第 4 条对照：保留 Video-DiT 但缓存 K/V，与直接丢掉视频主干，在 RoboTwin 上分数已经打平——问题变成哪条路线在真机和跨本体上更站得住。
